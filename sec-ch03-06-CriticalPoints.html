    Section 3.6 Critical Points and Analysis

    Note 3.6.1.

    Recall from Calculus I:
    🔗
    • A function \(f(x)\) has a local maximum at \(x=a\) if \(f(a) \geq f(x)\) for all \(x\) in some interval \((a-h, a+h), h \gt 0\text{.}\)
      🔗
      🔗
    • A function \(f(x)\) has a local minimum at \(x=b\) if \(f(b) \leq f(x)\) for all \(x\) in some interval \((b-h, b+h), h \gt 0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    🔗
    We have similar definitions for scalar-valued functions.
    🔗

    Definition 3.6.2. Local Minimums and Maximums.

    Given a function \(f(x, y)\) :
    🔗
    • \(f(x, y)\) has a local maximum at \((a, b)\) if \(f(a, b) \geq f(x, y)\) for all points \((x, y)\) inside some open circle of radius \(r \gt 0\) centered at \((a, b)\text{.}\)
      🔗
      🔗
    • \(f(x, y)\) has a local minimum at \((a, b)\) if \(f(a, b) \leq f(x, y)\) for all points \((x, y)\) inside some open circle of radius \(r \gt 0\) centered at \((a, b)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Note 3.6.3.

    This definition says that we must compare \(f(a, b)\) to all points inside some open circle in the domain of \(f\text{.}\) Moreover, we only need to find one such circle that works.
    🔗
    🔗

    Note 3.6.5.

    In Calculus I, when working with functions of one variable \(y=f(x)\text{,}\) we used critical points to find local maximums/minimums (places where the derivative is zero or doesn’t exist). We will do the same thing with functions of two or more variables.
    🔗
    🔗

    Definition 3.6.6. Critical Points.

    Given a function \(f(x, y)\text{,}\) we say that the interior point \((a, b)\) of the domain of \(f\) is a critical point of \(f\) if one of the following is true:
    🔗
    1. \(f_{x}(a, b)=0\) and \(f_{y}(a, b)=0\text{.}\)
      🔗
      🔗
    2. At least one of \(f_{x}(a, b)\) or \(f_{y}(a, b)\) does not exist.
      🔗
      🔗
    🔗
    🔗

    Remark 3.6.7.

    • If \((a, b ) \)is a critical point of \(f\) due to condition 1 , this implies the tangent plane to \(f\) at \((a, b, f(a, b))\) is horizontal.
      🔗
      🔗
    • Condition 2) is for the points that the function is not differentiable at.
      🔗
      🔗
    • If a function \(f(x, y)\) has a critical point at \((a, b)\text{,}\) this does not guarantee that \(f\) has a local maximum/minimum at \((a, b)\text{.}\) However, if \(f\) does have a local maximum/minimum at some point, it must occur at a critical point.
      🔗
      🔗
    🔗
    🔗

    Definition 3.6.8. Interior and Boundary Points.

    Given a set \(S\) in the \(x y\)-plane, we say that the point ( \(a, b\) ) is an interior point of \(S\) if there exists an open circle of radius \(r \gt 0\) centered at ( \(a, b\) ) that is entirely inside \(S\text{.}\)
    🔗
    Given a set \(S\) in the \(x y\)-plane, we say that the point \((a, b)\) is a boundary point of \(S\) if every open circle of radius \(r \gt 0\) centered at ( \(a, b\) ) lies partly inside and partly outside of \(S\text{.}\)
    🔗
    🔗

    Note 3.6.9.

    If the domain of a function \(f(x, y)\) is \(\mathbb{R}^{2}\text{,}\) then all points in its domain are interior points.
    🔗
    🔗

    Example 3.6.10.

    Find all critical points of the following functions:
    🔗
    (a) \(f(x, y)=x^{3}+3 x^{2}y+ 3xy^2+y^3\text{.}\)
    🔗
    (b) \(f(x, y)=e^{y}-y e^{x}\text{.}\)
    🔗
    Solution 1.
    Both partial derivatives exist at every point of \(\mathbb{R}^2\text{,}\) so the critical points come from solving \(f_x=0\) and \(f_y=0\) simultaneously. Computing the partial derivatives:
    \begin{gather*} f_x(x,y) = 3x^2 + 6xy + 3y^2 = 3(x+y)^2\\ f_y(x,y) = 3x^2 + 6xy + 3y^2 = 3(x+y)^2 \end{gather*}
    The two partial derivatives are identical, and \(3(x+y)^2 = 0 \Rightarrow x+y = 0 \Rightarrow y=-x\text{.}\) Hence every point on the line \(y=-x\) is a critical point of \(f\text{;}\) that is, the critical points are all the points of the form \((a,-a)\) with \(a\) any real number. (Notice that \(f(x,y)=(x+y)^3\text{,}\) which explains why an entire line of critical points appears.)
    🔗
    🔗
    Solution 2.
    Both partial derivatives exist at every point of \(\mathbb{R}^2\text{:}\)
    \begin{gather*} f_x(x,y) = -y e^{x}\\ f_y(x,y) = e^{y} - e^{x} \end{gather*}
    Since \(e^{x} \gt 0\) for every \(x\text{,}\) the equation \(f_x = 0\) forces \(y=0\text{.}\) Substituting \(y=0\) into \(f_y=0\) gives \(e^{0}-e^{x} = 0 \Rightarrow e^{x} = 1 \Rightarrow x = 0\text{.}\) Hence the only critical point of \(f\) is \((0,0)\text{.}\)
    🔗
    🔗
    🔗

    Example 3.6.11.

    Consider the function \(f(x, y)=x^2+y^2\text{.}\) This function has a critical point at \((0,0)\text{.}\) Does \((0,0)\) correspond to a local max, a local min, or neither?
    🔗
    Solution.
    We have \(f(0,0)=0\text{,}\) and since squares are never negative, \(f(x,y) = x^2+y^2 \geq 0 = f(0,0)\) for every point \((x,y)\) in the plane. In particular \(f(0,0)\leq f(x,y)\) for all points inside any open circle of radius \(r \gt 0\) centered at \((0,0)\text{,}\) and by the definition of local minimums, \(f\) has a local minimum at \((0,0)\text{.}\) In fact, since the inequality holds for every point of the plane and not just near the origin, \((0,0)\) is a global minimum: the graph of \(f\) is a paraboloid opening upwards with its vertex at the origin.
    🔗
    🔗
    🔗

    Remark 3.6.12. Three Classifications for Critical Points.

    Given a function \(f(x, y)\) and a critical point ( \(a, b\) ) of \(f\text{,}\) only one of three things can occur:
    🔗
    1. \(f\) has a local max at \((a, b)\text{.}\)
      🔗
      🔗
    2. \(f\) has a local min at \((a, b)\text{.}\)
      🔗
      🔗
    3. \(f\) has a saddle point at \((a, b)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Definition 3.6.13. Saddle Points.

    Given a function \(f(x, y), f\) has a saddle point at ( \(a, b\) ) if for all open circles of radius \(r \gt 0\) centered at ( \(a, b\) ), we can always find points \(\left(x_{0}, y_{0}\right)\) and \(\left(x_{1}, y_{1}\right)\) in the circle such that \(f(a, b) \lt f\left(x_{0}, y_{0}\right)\) and \(f(a, b) \gt f\left(x_{1}, y_{1}\right)\text{.}\)
    🔗
    🔗

    Example 3.6.14.

    Using the picture below, explain why the critical point \((0,0)\) of \(f(x, y)=2x^2-3y^2\) is a saddle point.
    🔗
    Graph of \(2x^2-3y^2\)
    🔗
    Solution.
    We have \(f(0,0)=0\text{.}\) Consider any open circle of radius \(r \gt 0\) centered at \((0,0)\text{.}\) Moving away from the origin along the \(x\)-axis (\(y=0\)), this is the direction in the picture along which the surface increases. Moving away from the origin along the \(y\)-axis (\(x=0\)), this is the direction in the picture along which the surface decreases. Since every open circle centered at \((0,0)\) contains points where \(f\) is larger than \(f(0,0)\) and points where \(f\) is smaller than \(f(0,0)\text{,}\) the critical point \((0,0)\) is neither a maximum nor a minimum.
    🔗
    🔗
    🔗
    Given a critical point \((a, b)\text{,}\) there is an algebraic way to determine whether it corresponds to a local min, local max, or a saddle point. Unfortunately, this method is not perfect.
    🔗

    Definition 3.6.15. Second Derivative Test.

    Suppose you have a function \(f(x, y)\) and a critical point \((a, b)\) of \(f\text{.}\) Let
    \begin{equation*} D(x, y)=f_{x x} f_{y y}-f_{x y}^{2} \end{equation*}
    🔗
    Then:
    🔗
    • \(f\) has a local maximum at \((a, b)\) if \(f_{x x}(a, b) \lt 0\) and \(D(a, b) \gt 0\text{.}\)
      🔗
      🔗
    • \(f\) has a local minimum at \((a, b)\) if \(f_{x x}(a, b) \gt 0\) and \(D(a, b) \gt 0\text{.}\)
      🔗
      🔗
    • \(f\) has a saddle point at \((a, b)\) if \(D(a, b) \lt 0\text{.}\)
      🔗
      🔗
    • The test is inconclusive at \((a, b)\) if \(D(a, b)=0\text{.}\)
      🔗
      🔗
    🔗
    We call the function \(D(x, y)\) the discriminant of \(f\text{.}\)
    🔗
    🔗

    Example 3.6.16.

    Find and classify the critical points of \(f(x, y)=x^3+3x^2y+3xy^2+y^3+3y^2+6y-3x\text{.}\)
    🔗
    Solution.
    Both partial derivatives exist at every point of \(\mathbb{R}^2\text{,}\) so we solve \(f_x=0\) and \(f_y=0\) simultaneously. Computing the partial derivatives:
    \begin{gather*} f_x(x,y) = 3x^2 + 6xy + 3y^2 - 3 = 3(x+y)^2 - 3\\ f_y(x,y) = 3x^2 + 6xy + 3y^2 + 6y + 6 = 3(x+y)^2 + 6y + 6 \end{gather*}
    Setting \(f_x = 0\) gives \(3(x+y)^2 = 3 \Rightarrow (x+y)^2 = 1 \Rightarrow x+y = 1\) or \(x+y=-1\text{.}\) In either case \((x+y)^2 = 1\text{,}\) so setting \(f_y=0\) gives
    \begin{equation*} 3(1) + 6y + 6 = 0 \Rightarrow 6y = -9 \Rightarrow y = -\frac{3}{2} \end{equation*}
    If \(x+y=1\) then \(x = 1-\left(-\frac{3}{2}\right) = \frac{5}{2}\text{,}\) and if \(x+y=-1\) then \(x = -1-\left(-\frac{3}{2}\right) = \frac{1}{2}\text{.}\) Hence the critical points are \(\left(\frac{5}{2},-\frac{3}{2}\right)\) and \(\left(\frac{1}{2},-\frac{3}{2}\right)\text{.}\)
    🔗
    To classify them we use the Second Derivative Test. The second partial derivatives are
    \begin{equation*} f_{xx} = 6x+6y = 6(x+y), \quad f_{yy} = 6x+6y+6 = 6(x+y)+6, \quad f_{xy} = 6x+6y = 6(x+y) \end{equation*}
    so the discriminant is
    \begin{gather*} D(x,y) = f_{xx}f_{yy} - f_{xy}^2 = 6(x+y)\left[ 6(x+y)+6 \right] - \left[ 6(x+y) \right]^2\\ = 36(x+y)^2 + 36(x+y) - 36(x+y)^2 = 36(x+y) \end{gather*}
    At \(\left(\frac{5}{2},-\frac{3}{2}\right)\) we have \(x+y=1\text{,}\) so \(D = 36 \gt 0\) and \(f_{xx} = 6 \gt 0\text{;}\) hence \(f\) has a local minimum at \(\left(\frac{5}{2},-\frac{3}{2}\right)\text{.}\) At \(\left(\frac{1}{2},-\frac{3}{2}\right)\) we have \(x+y=-1\text{,}\) so \(D = -36 \lt 0\text{;}\) hence \(f\) has a saddle point at \(\left(\frac{1}{2},-\frac{3}{2}\right)\text{.}\)
