    Section 2.1 Vector-Valued Functions

    Note 2.1.1.

    Think of a point tracing a path as it moves through \(x y z\)-space (for example, think of tracing the path a mosquito travels as it flies through a room). We can think of the curve traced by this point in two ways:
    🔗
    1. The position of the point at a time \(t\text{,}\) given by \((x(t), y(t), z(t))\text{.}\)
      🔗
      🔗
    2. The position of the point at a time \(t\text{,}\) given by the endpoint of the vector \(\vec{r}(t)=\langle x(t), y(t), z(t)\rangle\text{.}\)
      🔗
      🔗
    🔗
    🔗

    🔗

    Definition 2.1.2. Vector-Valued Function.

    A vector-valued function is a function which assigns to each input \(t\) (the independent variable), an output of a vector. Mathematically, a vector-valued function can be written in the form
    \begin{equation*} \vec{r}(t)=\langle f(t), g(t), h(t)\rangle, a \leq t \leq b \end{equation*}
    where each component of \(\vec{r}(t)\) is a function of \(t\) (each component is a dependent variable).
    🔗
    🔗

    Remark 2.1.3.

    The domain of \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle\) is the intersection of the domains of \(f(t), g(t)\text{,}\) and \(h(t)\text{.}\)
    🔗
    🔗

    Example 2.1.4.

    The graph of \(\vec{r}(t)=\left\langle\cos (t), \sin (t), \frac{t}{10}\right\rangle\text{,}\) \(0 \leq t \leq 10\) is shown below. If we don’t restrict \(t\text{,}\) what is the domain of \(\vec{r}(t)\) ?
    🔗
    Solution.
    The domain of \(\vec{r}(t)\) is the intersection of the domains of its three components. Each of \(\cos(t)\text{,}\) \(\sin(t)\text{,}\) and \(\frac{t}{10}\) is defined for every real number \(t\text{,}\) so
    \begin{equation*} \operatorname{dom}(\vec{r}) = (-\infty, \infty) \end{equation*}
    that is, the domain is all real numbers (and the graph becomes a helix spiraling upwards forever in both directions).
    🔗
    🔗
    🔗

    Note 2.1.5.

    If we write \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle\) and don’t specify an interval, assume that \(t\) can take any possible value in the domain of \(\vec{r}(t)\text{.}\)
    🔗
    🔗

    Remark 2.1.6.

    The output vector of a vector-valued function doesn’t have to be three dimensional. For example, the function \(\vec{r}(t)=\langle t, -\frac{t}{2}+1\rangle,0 \leq t \leq 2\) traces the graph of \(y=-\frac{x}{2}+1\) on the interval \([0,2]\text{.}\)
    🔗
    🔗

    Note 2.1.7.

    Since vector-valued functions trace a curve as time passes by, we can talk about the orientation (or direction) in which the curve is traced.
    🔗
    🔗

    Example 2.1.8.

    For each of the following planar curves, write a vector-valued function which traces them with the specified orientation. Moreover, graph the given curves using arrows to indicate the orientation.
    🔗
    1. A circle of radius 1 (traced once) oriented counterclockwise, starting at \((1,0)\text{.}\)
      🔗
      🔗
    2. The graph of \(y=x^{2}-1\text{,}\) on the interval \([-1,1]\text{,}\) traced from left to right (relative to the \(x\)-axis).
      🔗
      🔗
    🔗
    Solution 1.
    The function
    \begin{equation*} \vec{r}(t) = \langle \cos(t), \sin(t) \rangle, \quad 0 \leq t \leq 2\pi \end{equation*}
    traces the circle of radius 1 centered at the origin, since \(x(t)^2+y(t)^2 = \cos^2(t)+\sin^2(t) = 1\text{.}\) It starts at \(\vec{r}(0) = \langle 1,0 \rangle\text{,}\) passes through \((0,1)\) at \(t=\frac{\pi}{2}\text{,}\) through \((-1,0)\) at \(t=\pi\text{,}\) and through \((0,-1)\) at \(t=\frac{3\pi}{2}\) – a counterclockwise motion – and returns to \((1,0)\) at \(t=2\pi\text{,}\) tracing the circle exactly once. To graph it, draw the unit circle with the arrows on it pointing counterclockwise.
    🔗
    🔗
    Solution 2.
    Letting \(x=t\text{,}\) the point on the graph above \(x\) is \((t, t^2-1)\text{,}\) so
    \begin{equation*} \vec{r}(t) = \langle t, t^2-1 \rangle, \quad -1 \leq t \leq 1 \end{equation*}
    🔗
    Since \(x(t)=t\) increases as \(t\) increases, the parabola is traced from left to right: starting at \((-1,0)\text{,}\) down to the vertex \((0,-1)\text{,}\) and up to \((1,0)\text{.}\) To graph it, draw this piece of the upward parabola with the arrows on it pointing from left to right.
    🔗
    🔗
    🔗

    Remark 2.1.9.

    Generally if you want to quickly parametrize a function \(f(x)\) on the interval \(x\in [a,b]\) from left to right, then you can use \(\vec{r}(t) = \langle t, f(t) \rangle\) for \(t\in [a,b]\text{.}\)
    🔗
    🔗

    Example 2.1.10.

    For the following planar curve, write a vector-valued function which traces it with the specified orientation. Moreover, graph the given curve using arrows to indicate the orientation.
    🔗
    The graph of \(y=x^{2}-4 x+3\text{,}\) on the interval \([1,5]\text{,}\) traced from right to left (relative to the \(x\)-axis)
    🔗
    Solution.
    To trace the graph from right to left we need the \(x\)-coordinate to decrease as \(t\) increases and there multiple options to achieve this. Here are three:
    🔗
    Option A Let \(x = 5-t\text{.}\) Then
    \begin{equation*} y = x^2-4x+3 = (5-t)^2-4(5-t)+3 = t^2-6t+8 \end{equation*}
    and \(x=5-t\) runs from 5 down to 1 as \(t\) runs from 0 to 4. Hence
    \begin{equation*} \vec{r}(t) = \langle 5-t, t^2-6t+8 \rangle, \quad 0 \leq t \leq 4 \end{equation*}
    🔗
    Indeed, \(\vec{r}(0) = \langle 5,8 \rangle\) and \(\vec{r}(4) = \langle 1,0 \rangle\text{,}\) so the curve starts at the right endpoint \((5,8)\) and ends at the left endpoint \((1,0)\text{.}\)
    🔗
    Option B Let \(x = 6-t\text{.}\) Then
    \begin{equation*} y = x^2-4x+3 = (6-t)^2-4(6-t)+3 = t^2-8t+15 \end{equation*}
    and \(x=6-t\) runs from 5 down to 1 as \(t\) runs from 1 to 5. Hence
    \begin{equation*} \vec{r}(t) = \langle 6-t, t^2-8t+15 \rangle, \quad 1 \leq t \leq 5 \end{equation*}
    🔗
    Indeed, \(\vec{r}(1) = \langle 5,8 \rangle\) and \(\vec{r}(5) = \langle 1,0 \rangle\text{,}\) so the curve starts at the right endpoint \((5,8)\) and ends at the left endpoint \((1,0)\text{.}\)
    🔗
    Option C Let \(x = -t\text{.}\) Then
    \begin{equation*} y = x^2-4x+3 = (-t)^2-4(-t)+3 = t^2+4t+3 \end{equation*}
    and \(x=-t\) runs from 5 down to 1 as \(t\) runs from \(-5\) to \(-1\text{.}\) Hence
    \begin{equation*} \vec{r}(t) = \langle -t, t^2+4t+3 \rangle, \quad -5 \leq t \leq -1 \end{equation*}
    🔗
    Indeed, \(\vec{r}(-5) = \langle 5,8 \rangle\) and \(\vec{r}(-1) = \langle 1,0 \rangle\text{,}\) so the curve starts at the right endpoint \((5,8)\) and ends at the left endpoint \((1,0)\text{.}\)
    🔗
    To graph it, draw the piece of the upward parabola with vertex \((2,-1)\) and \(x\)-intercepts \((1,0)\) and \((3,0)\text{,}\) between \(x=1\) and \(x=5\text{,}\) with the arrows on it pointing from right to left.
    🔗
    🔗
    🔗

    Remark 2.1.11.

    Generally if you want to quickly parametrize a function \(f(x)\) on the interval \(x\in [a,b]\) from right to left, then you can use on of the following.
    🔗
    1. \(\vec{r}(t) = \langle b-t, f(b-t) \rangle\) for \(t\in [0,b-a]\text{.}\)
      🔗
      🔗
    2. \(\vec{r}(t) = \langle b+a-t, f(b+a-t) \rangle\) for \(t\in [a,b]\text{.}\)
      🔗
      🔗
    3. \(\vec{r}(t) = \langle -t, f(-t) \rangle\) for \(t\in [-b,-a]\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Remark 2.1.12. Parametric Equations for a Line.

    The components \(f(t), g(t)\text{,}\) and \(h(t)\) of \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle\) are also called parametric equations.
    🔗
    🔗

    Definition 2.1.13. Line in Parametric Form.

    A line in \(x y z\)-space (or in 2D space) can be defined as a vector-valued function by the equation
    \begin{align*} \vec{r}(t) \amp =\vec{r}_{0}+t \vec{v}\\ \amp =\left\langle x_{0}, y_{0}, z_{0}\right\rangle+t\langle a, b, c\rangle\\ \amp =\left\langle x_{0}+a t, y_{0}+b t, z_{0}+c t\right\rangle \end{align*}
    where \(-\infty \lt t \lt \infty, P_{0}\left(x_{0}, y_{0}, z_{0}\right)\) is any point on the line, and \(\vec{v}=\langle a, b, c\rangle\) (the direction vector) gives you the change in each coordinate.
    🔗
    The equations \(f(t)=x_{0}+a t, g(t)=y_{0}+b t\text{,}\) and \(h(t)=z_{0}+c t\) are the parametric equations that define the line.
    🔗
    🔗

    Note 2.1.14.

    Geometrically, the definition above says that you take the line containing \(\vec{v}\) (represented by \(t \vec{v}\) ), and shift it so it passes through the endpoint of \(\vec{r}_{0}\text{.}\)
    🔗
    🔗

    Example 2.1.15.

    Find both the vector equation and the parametric equations of the line through \(P(1,2,3)\) in the direction of the vector \(\vec{v}=\langle 3,2,1 \rangle\text{.}\) Does the point \(\left(\frac{5}{4},\frac{13}{6},\frac{37}{12}\right)\) lie on this line?
    🔗
    Solution.
    Using \(P(1,2,3)\) as the point on the line and \(\vec{v}=\langle 3,2,1 \rangle\) as the direction vector, the vector equation of the line is
    \begin{equation*} \vec{r}(t) = \vec{r}_0+t\vec{v} = \langle 1,2,3 \rangle + t\langle 3,2,1 \rangle = \langle 1+3t, 2+2t, 3+t \rangle, \quad -\infty \lt t \lt \infty \end{equation*}
    and the parametric equations are
    \begin{equation*} x = 1+3t, \quad y = 2+2t, \quad z = 3+t \end{equation*}
    🔗
    For the point \(\left(\frac{5}{4},\frac{13}{6},\frac{37}{12}\right)\) to lie on the line, all three parametric equations must be satisfied by the same value of \(t\text{.}\) From the first equation:
    \begin{equation*} 1+3t = \frac{5}{4} \Rightarrow 3t = \frac{1}{4} \Rightarrow t = \frac{1}{12} \end{equation*}
    🔗
    Checking this value in the other two equations:
    \begin{equation*} y = 2+2 \cdot \frac{1}{12} = 2+\frac{1}{6} = \frac{13}{6}, \quad z = 3+\frac{1}{12} = \frac{37}{12} \end{equation*}
    🔗
    Both match, so yes: the point lies on the line (it is reached at \(t = \frac{1}{12}\)).
    🔗
    🔗
    🔗

    Remark 2.1.16.

    Given a line \(\vec{r}(t)=\vec{r}_{0}+t \vec{v}\text{,}\) since \(\vec{v}\) represents the direction of the line, we can compare lines by comparing their direction vectors.
    🔗
    🔗

    Example 2.1.17.

    Determine whether the following pair of lines are parallel, intersect at a single point, or are skew. If they are parallel, determine whether they are the same line. If they intersect at a single point, determine the point of intersection.
    \begin{align*} \amp \vec{r}_{1}(t)=\langle 3,2,1\rangle+\langle 1,2,3 \rangle t,\quad -\infty \lt t \lt \infty\\ \amp \vec{r}_{2}(t)=\langle 1,2,3\rangle+\langle 3,2,1 \rangle t,\quad -\infty \lt t \lt \infty \end{align*}
    🔗
    Solution.
    The direction vectors are \(\vec{v}_1 = \langle 1,2,3 \rangle\) for the first line and \(\vec{v}_2 = \langle 3,2,1 \rangle\) for the second. If the lines were parallel there would be a scalar \(c\) with \(c\vec{v}_1 = \vec{v}_2\text{;}\) comparing components gives \(c=3\text{,}\) \(c=1\text{,}\) and \(c=\frac{1}{3}\) respectively, which is impossible. Hence the lines are not parallel (and in particular they are not the same line).
    🔗
    It remains to determine whether the lines intersect at a single point or are skew. An intersection point may be reached by each line at a different time, so we rename the parameter of the second line and look for values \(t\) and \(s\) with \(\vec{r}_1(t) = \vec{r}_2(s)\text{.}\) Comparing components gives the system
    \begin{gather*} 3+t = 1+3s\\ 2+2t = 2+2s\\ 1+3t = 3+s \end{gather*}
    🔗
    The second equation of the system gives \(2t = 2s \Rightarrow t = s\text{.}\) Substituting into the first equation:
    \begin{equation*} 3+t = 1+3t \Rightarrow 2 = 2t \Rightarrow t = 1, \quad s = 1 \end{equation*}
    🔗
    Since we only used the first two equations, we must check these values in the third: \(1+3(1) = 4\) and \(3+1 = 4\text{,}\) so the third equation is also satisfied. Hence the system is consistent and the lines intersect at the single point
    \begin{equation*} \vec{r}_1(1) = \langle 3+1, 2+2, 1+3 \rangle = \langle 4,4,4 \rangle \end{equation*}
    that is, at the point \((4,4,4)\text{.}\) (Indeed, \(\vec{r}_2(1) = \langle 1+3, 2+2, 3+1 \rangle = \langle 4,4,4 \rangle\) as well.)
