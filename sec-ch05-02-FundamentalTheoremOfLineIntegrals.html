    Section 5.2 Fundamental Theorem of Line Integrals

    Note 5.2.1. Conservative Vector Fields.

    As we discussed, given a vector field \(\vec{F}\text{,}\) two points \(P\) and \(Q\) in its domain ( \(P\) could be equal to \(Q\) ), and two different curves \(C_{1}\) and \(C_{2}\) connecting \(P\) to \(Q\text{,}\) in most cases,
    \begin{equation*} \int_{C_{1}} \vec{F} \cdot \vec{T} d s \neq \int_{C_{2}} \vec{F} \cdot \vec{T} d s \end{equation*}
    🔗
    • In general, different curves connecting two points give different values for line integrals.
      🔗
      🔗
    🔗
    However, there is a way we can guarantee that for any path \(C\) with starting point \(P\) and ending point \(Q\text{,}\) then \(\int_{C} \vec{F} \cdot \vec{T} d s\) always has the same value independent of which path you take. We do this by working with conservative vector fields.
    🔗
    🔗

    Definition 5.2.2. Conservative Vector Fields.

    A vector field \(\vec{F}=\langle f(x, y, z), g(x, y, z), h(x, y, z)\rangle\) is said to be conservative if there exists a scalar valued function \(\varphi(x, y, z)\text{,}\) with continuous partial derivatives, such that
    \begin{equation*} \vec{F}=\nabla \varphi=\left\langle\varphi_{x}, \varphi_{y}, \varphi_{z}\right\rangle \end{equation*}
    🔗
    Equivalently, if
    \begin{align*} \varphi_{x} \amp =f(x, y, z)\\ \varphi_{y} \amp =g(x, y, z)\\ \varphi_{z} \amp =h(x, y, z)\text{.} \end{align*}
    🔗
    We call such a function \(\varphi\) a potential function for \(\vec{F}\text{.}\)
    🔗
    🔗

    Example 5.2.3.

    Verify that \(\varphi(x, y)=x^3+2y+y^2\) is a potential function for \(\vec{F}=\langle 3x^2, 2y+2\rangle\) (so that \(\vec{F}\) is conservative).
    🔗
    Solution.
    \begin{equation*} \left. \begin{matrix} \varphi_x = 3 x^2\\ \varphi_y = 2+2y \end{matrix} \right\} \Rightarrow \nabla \varphi (x,y) = \langle 3x^2 , 2+2y \rangle = \vec F \end{equation*}
    🔗
    🔗
    🔗

    Note 5.2.4.

    In general, finding a function \(\varphi\) such that \(\nabla \varphi=\vec{F}\) is hard, hence, we developed an easier test to determine whether a vector field is conservative.
    🔗
    From now on, we will assume the regions we discuss are open (don’t contain their boundary).
    🔗
    🔗

    Remark 5.2.5. Test for Conservative Vector Fields.

    Let \(\vec{F}=\langle f, g, h\rangle\) be a vector field defined on a connected and simply connected region \(D\text{,}\) and suppose that \(f, g\text{,}\) and \(h\) have continuous partial derivatives on \(D\text{.}\) Then \(\vec{F}\) is conservative on \(D\) if and only if
    \begin{equation*} \frac{\partial f}{\partial y}=\frac{\partial g}{\partial x}, \frac{\partial f}{\partial z}=\frac{\partial h}{\partial x}, \quad \text { and } \quad \frac{\partial g}{\partial z}=\frac{\partial h}{\partial y}\text{.} \end{equation*}
    🔗
    If \(\vec{F}=\langle f, g\rangle\text{,}\) then you only have to check the condition
    \begin{equation*} \frac{\partial f}{\partial y}=\frac{\partial g}{\partial x}\text{.} \end{equation*}
    🔗
    🔗
    This is an example of how a connected and simply connected region looks/does not look like:
    🔗

    Example 5.2.6.

    Determine whether the following vector fields are conservative over their domain:
    🔗
    All the components of the vector fields below are polynomials defined on the entire \(xy\)-plane. Hence we can apply the aforementioned test.
    🔗
    (a) \(\vec{F}=\left\langle 3x^2+2xy+y^2, x^2+2xy+1 \right\rangle\)
    🔗
    (b) \(\vec{F}=\langle yz+y, xz+x,xy+x+y\rangle\text{.}\)
    🔗
    Solution 1.
    \begin{gather*} f(x,y)= 3x^2+2xy+y^2 , \ g(x,y) = x^2+2xy+1\\ f_y = \frac{\partial}{\partial y}(3x^2+2xy+y^2) = 2x +2y, \ g_x =\frac{\partial}{\partial x}(x^2+2xy+1)=2x+2y\\ \vec F \text{ is conservative since they are equal} \end{gather*}
    🔗
    🔗
    Solution 2.
    \begin{gather*} f(x,y,z)= yz+y , \ g(x,y,z) = xz+x, \ h(x,y,z) = xy+x+y\\ f_y = \frac{\partial}{\partial y}(yz+y) =z +1, \ g_x = \frac{\partial}{\partial x}(xz+x)=z+1\\ \ f_z =\frac{\partial}{\partial z}(yz+y) = y, \ \ h_x = \frac{\partial}{\partial x}(xy+x+y) = y+1 \text{ they are not equal}\\ g_z = \frac{\partial}{\partial z}(xz+x) = x, \ \ h_y = \frac{\partial}{\partial y}(xy+x+y) = x+1 \text{ they are not equal}\\ \vec F \text{ is not conservative.} \end{gather*}
    🔗
    🔗
    🔗

    Note 5.2.7.

    Once we know a vector field is conservative, now we can put in the effort to find a potential function for it.
    🔗
    🔗

    Example 5.2.8.

    Find a potential function for the conservative vector field \(\vec{F}=\left\langle 3x^2+2xy+y^2, x^2+2xy+1 \right\rangle\text{.}\)
    🔗
    Solution.
    A potential function \(\varphi\) would satisfy \(\nabla \varphi = \vec F\) and that would imply that \(\varphi_x = 3x^2+2xy+y^2\) and \(\varphi_y = x^2+2xy+1\text{.}\) Now:
    \begin{gather*} \int \varphi_x \ dx = \int 3x^2+2xy+y^2 \ dx = x^3 +x^2y + y^2x +f(y)\\ \int \varphi_y \ dy = \int x^2 +2xy+1 dy = x^2y+xy^2+y +g(x) \end{gather*}
    Notice that the terms of the above polynomials that depend on both \(x\) and \(y\) are equal, as one would expect since their corresponding partials would appear in both \(\varphi_x\) and \(\varphi_y\text{.}\) This allows for \(f(y)=y\) (the non-common part of the polynomials that depends only on \(y\)) and \(g(x) = x^3\) (the non-common part of the polynomials that depends only on \(x\)). Hence \(\varphi (x,y) = x^2y+xy^2+x^3+y\)
    🔗
    🔗
    🔗

    Example 5.2.9.

    Find a potential function for the conservative vector field \(\vec{F}= \left\langle 2 x y-9 x^{2}, 2 y+x^{2}+1\right\rangle\text{.}\)
    🔗
    Solution.
    A potential function \(\varphi\) would satisfy \(\nabla \varphi = \vec F\) and that would imply that \(\varphi_x = 2 x y-9 x^{2}\) and \(\varphi_y = 2y+x^{2}+1\text{.}\) Now:
    \begin{gather*} \int \varphi_x \ dx = \int 2 x y-9 x^2 \ dx = x^2y -3x^3 +f(y)\\ \int \varphi_y \ dy = \int 2y+x^{2}+1 dy = y^2+x^2y+y +g(x) \end{gather*}
    Notice that the terms of the above polynomials that depend on both \(x\) and \(y\) are equal, as one would expect since their corresponding partials would appear in both \(\varphi_x\) and \(\varphi_y\text{.}\) This allows for \(f(y)=y^2+y\) (the non-common part of the polynomials that depends only on \(y\)) and \(g(x) = -3x^3\) (the non-common part of the polynomials that depends only on \(x\)). Hence \(\varphi (x,y) = x^2y-3x^3+y^2+y\)
    🔗
    🔗
    🔗

    Remark 5.2.10. Conservative Vector Fields and Path Independence.

    A vector field \(\vec{F}\text{,}\) defined over an open connected region, is path independent if and only if it is conservative.

    Example 5.2.11.

    Consider the vector field \(\vec{F}=\left\langle xy^{2}, y x^2+1\right\rangle\) and the two paths shown above connecting the points \((0,0)\) and \((1,1)\text{.}\)
    🔗
    (a) Determine whether \(\vec{F}\) is conservative.
    🔗
    (b) Evaluate the vector line integral over the first path.
    🔗
    (c) Use your answer for part (b) and path independence to evaluate the line integral over the second path
    🔗
    Solution 1.
    All the components of the vector field are polynomials defined on the entire \(xy\)-plane. Hence one can apply the aforementioned test.
    \begin{equation*} f_y =\frac{\partial}{\partial y}(xy^2) = 2xy, \ g_x=\frac{\partial}{\partial x} (yx^2+1) = 2xy, \text{ and since those are equal, }\vec F\text{ is conservative} \end{equation*}
    🔗
    🔗
    Solution 2.
    \begin{gather*} \vec r(t)=\langle 0,0 \rangle + t \langle 1,1 \rangle = \langle t,t \rangle, \ 0\leq t \leq 1, \ \vec r'(t) = \langle 1,1 \rangle\\ \vec F (\vec r (t)) = \langle t^3 , t^3+1 \rangle, \ \vec F (\vec r (t))\cdot \vec r ' (t) = t^3+t^3+1 = 2t^3+1\\ \int_0^1 \vec F (\vec r (t))\cdot \vec r ' (t) \ dt = \int_0^1 2t^3+1 \ dt =\left . \frac{t^4}{2}+t \right |_0^1 = \frac{1}{2}+1 = \frac{3}{2} \end{gather*}
    🔗
    🔗
    Solution 3.
    From the fact that \(\vec F\) is conservative we have path independence and hence the answer is the same as part (b) \(\frac{3}{2}\text{.}\)
    🔗
    🔗
    🔗

    Theorem 5.2.12. Fundamental Theorem of Line Integrals.

    Suppose that \(\vec{F}\) is conservative over an open, connected, simply connected region \(D\) and that the function \(\varphi\) satisfies \(\nabla \varphi=\vec{F}\text{.}\) Then
    \begin{equation*} \int_{C} \vec{F} \cdot \vec{T} d s=\varphi(B)-\varphi(A)\text{,} \end{equation*}
    where \(C\) is any (piece-wise) smooth path from the point \(A\) to the point \(B\text{.}\)
    🔗
    🔗

    Example 5.2.13.

    Verify that the function \(\phi (x,y)=\frac{x^2y^2}{2}+y\) satisfies \(\nabla \phi=\vec{F}\text{,}\) where \(\vec{F}=\left\langle xy^{2}, y x^2+1\right\rangle\text{.}\) Use the fundamental theorem of line integrals to evaluate the vector line integral over the path shown below.
    🔗
    \begin{equation*} y= x, 0 \leq x \leq 1 \end{equation*}
    🔗
    Solution.
    \begin{gather*} \varphi_x = xy^2, \ \varphi_y = x^2y+1 \Rightarrow \nabla \varphi = \vec F\\ \int_C \vec F \cdot \vec T \ ds = \varphi (1,1)-\varphi (0,0) = \frac{1}{2}+1 -\frac{0}{2}-0 = \frac{3}{2} \end{gather*}
    🔗
    🔗
    🔗

    Note 5.2.14.

    The Fundamental Theorem of Line Integrals tells us what happens when we integrate a conservative vector field over a simple and closed curve.
    🔗
    🔗

    Remark 5.2.15. Loop Property.

    Let \(R\) be an open and connected region. Then \(\vec{F}\) is conservative on \(R\) if and only if \(\oint_{C} \vec{F} \cdot \vec{T} d s=0\) for all simple, closed, and piecewise smooth curves in \(R\text{.}\)
    🔗
    🔗

    Example 5.2.16.

    Explain why the loop property holds if you start with a conservative vector field \(\vec{F}\) and a SCPS curve \(C\text{.}\)
    🔗
    Solution.
    Assume that a SCPS curve \(C\) has \(n\) smooth pieces, \(C_1\) from point \(P_1\) to point \(P_2\text{,}\) \(C_2\) from \(P_2\) to \(P_3\text{,}\) \(\ldots\text{,}\) and \(C_n\) from \(P_{n}\) all the way back to \(P_1\) and assume that \(\nabla \varphi = \vec F\) . Then
    \begin{gather*} \int_C \vec F \cdot \vec T \ ds = \int_{C_1} \vec F \cdot \vec T \ ds + \int_{C_2} \vec F \cdot \vec T \ ds +\cdots + \int_{C_n} \vec F \cdot \vec T \ ds =\\ \left ( \varphi (P_2) - \varphi (P_1)\right ) +\left ( \varphi (P_3) - \varphi (P_2)\right ) + \cdots + \left ( \varphi (P_1) - \varphi (P_n)\right ) =\\ \text{by reordering one can see that}\\ - \varphi (P_1) + \cancelto{0}{\varphi (P_2) - \varphi (P_2)} + \cancelto{0}{\varphi (P_3) - \varphi (P_3)} + \cdots + \cancelto{0}{\varphi (P_n ) - \varphi (P_n)} + \varphi (P_1) =\\ - \varphi (P_1)+\varphi (P_1) = 0 \end{gather*}
    🔗
    🔗
    🔗

    Remark 5.2.17.

    We use the integral symbol \(\oint\) to emphasize we are integrating over a simple and closed curve.
    🔗
    🔗

    Example 5.2.18.

    Evaluate \(\oint_{C} \vec{F} \cdot \vec{T} d s\) where \(\vec{F}=\langle y, x\rangle\) and \(C\) is the unit circle (with a given orientation).
    🔗
    Solution.
    The unit circle is a SCPS curve. Notice that \(\vec F\) is conservative since \(\varphi (x,y) = xy\) is a potential function for it. One can also notice that all the components of the vector field are polynomials defined on the entire \(xy\)-plane. Hence one can apply the test \(f_y = \frac{\partial}{\partial y}y = \frac{\partial}{\partial x}x = g_x\) which yields the same conclusion. By the fundamental theorem of line integrals and the loop property
    \begin{equation*} \oint_C \vec F\cdot \vec T ds = 0 \end{equation*}
    🔗
    🔗
    🔗

    Remark 5.2.19.

    The test given for conservative vector fields only works over connected and simply connected regions.
    🔗
    🔗

    Example 5.2.20.

    You can verify that \(\vec{F}=\left\langle\frac{-y}{x^{2}+y^{2}}, \frac{x}{x^{2}+y^{2}}\right\rangle\) satisfies \(\frac{\partial f}{\partial y}=\frac{\partial g}{\partial x}\text{,}\) however, the vector line integral of \(\vec{F}\) over \(\vec{r}(t)=\langle\cos (t), \sin (t)\rangle, 0 \leq t \leq 2 \pi\text{,}\) is \(2 \pi\) instead of zero. Why is this the case?
    🔗
    Solution.
    Indeed
    \begin{gather*} f_y =\frac{\partial}{\partial y}\frac{-y}{x^2+y^2} = \frac{-(x^2+y^2) - (-y)(2y)}{(x^2+y^2)^2} = \frac{-(x^2+y^2)+2y^2}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2}\\ g_x = \frac{\partial}{\partial x} \frac{x}{x^2+y^2} = \frac{(x^2+y^2) - x(2x)}{(x^2+y^2)^2} = \frac{(x^2+y^2)-2x^2}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2}\\ \vec r'(t) = \langle -\sin(t) , \cos (t) \rangle, \ \vec F (\vec r (t)) = \langle -\sin(t) , \cos (t) \rangle , \ \vec F (\vec r (t))\cdot \vec r' (t) = \sin^2 (t) + \cos^2 (t) =1\\ \int_0^{2\pi} \vec F (\vec r (t))\cdot \vec r' (t)\ dt = \int_0^{2\pi} 1 \ dt =2\pi \end{gather*}
    The issue here is that the test \(f_y=g_x\) was applied improperly. The domain of those functions is not simply connected. They are not defined at \(O(0,0)\text{,}\) thus the domain has a hole and it is not simply connected. Moreover, this hole is enclosed by the curve of the vector line integral.
    🔗
    Another way to arrive at that conclusion is to try to find a function for which \(\nabla \varphi =\vec F\text{.}\) At first glance that function should be \(\varphi (x,y)= - \arctan \left ( \frac{x}{y} \right)\text{.}\) But this function, and by extension its partials, is not defined on the \(x\)-axis (\(y=0\)). Hence \(\nabla \varphi\) is not equal to \(\vec F\text{,}\) since the latter is defined at all points of the \(x\)-axis apart from the origin \(O(0,0)\text{.}\)
