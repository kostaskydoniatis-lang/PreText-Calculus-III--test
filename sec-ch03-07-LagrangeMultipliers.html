    Section 3.7 Constraints and Lagrange Multipliers

    Note 3.7.1.

    In the previous section, we found how to find local extremum of a function \(f(x, y)\) in the interior of its domain.
    🔗
    In practice, we sometimes restrict the domain of a function to a subset of its domain, and this subset sometimes will have boundaries. In this section, we will learn how to deal with these boundaries.
    🔗
    🔗

    Note 3.7.2.

    Before, we were interested in finding local max/min values. Now, we will expand our search to absolute max/min values.
    🔗
    🔗

    Definition 3.7.3. Absolute Maximum and Minimum Values.

    Given a function \(f(x, y)\text{,}\) a set \(R\) in its domain, and a point \((a, b)\) in \(R\text{,}\) then:
    🔗
    • \(f\) has an absolute maximum in \(R\) at \((a, b)\) if \(f(a, b) \geq f(x, y)\) for all \((x, y)\) in \(R\text{.}\)
      🔗
      🔗
    • \(f\) has an absolute minimum in \(R\) at \((a, b)\) if \(f(a, b) \leq f(x, y)\) for all \((x, y)\) in \(R\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.7.4.

    Suppose we restrict the domain of the function \(f(x, y)=\frac{y-x}{4}\) to the set
    \begin{equation*} R=\left\{(x, y) \mid \frac{1}{2}\leq y \leq \frac{3}{2}, 0 \leq x \leq \frac{3}{2}\right\}\text{.} \end{equation*}
    Under this restriction, \(f\) has an absolute maximum at the point \(\left(0,\frac{3}{2},\frac{3}{8}\right)\) )and an absolute minimum at the point \(\left(\frac{3}{2},\frac{1}{2},-\frac{1}{4}\right)\) , as shown below.
    🔗
    🔗

    Remark 3.7.5. Method of Lagrange Multipliers.

    Given a surface \(f(x, y)\) (called the objective function), we will look at domain restrictions (called constraints) of the form \(g(x, y)=0\text{.}\)
    🔗
    • Note that \(g(x, y)=0\) is a curve in the \(x y\)-plane (since it is \(g(x, y)\) intersected with \(z=0\) ).
      🔗
      🔗
    • We will require that all of the curve \(g(x, y)=0\) is in the interior of the domain of \(f\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 3.7.6.

    Below we have the function \(f(x, y)=\frac{y-x}{4}\) restricted (constrained) to points from the curve \((x-2)^{2}+(y-2)^{2}=1\text{.}\)
    🔗
    Write this constraint in the form \(g(x, y)=0\text{.}\)
    🔗
    \(f(x, y)=\frac{y-x}{4}\text { restricted to the circle }(x-2)^{2}+(y-2)^{2}=1\)
    🔗
    Solution.
    To write the constraint in the form \(g(x,y)=0\) we move everything to one side of the equation. Subtracting \(1\) from both sides of \((x-2)^{2}+(y-2)^{2}=1\) gives
    \begin{equation*} (x-2)^{2}+(y-2)^{2}-1 = 0 \end{equation*}
    so the constraint is \(g(x,y) = (x-2)^{2}+(y-2)^{2}-1\text{.}\) Note that the curve \(g(x,y)=0\) is the circle of radius \(1\) centred at \((2,2)\) in the \(xy\)-plane, which lies entirely in the interior of the domain of \(f\) (the whole plane).
    🔗
    🔗
    🔗
    Now, we give a method to find the absolute \(\mathrm{max} / \mathrm{min}\) values of a surface \(f(x, y)\) subject to a constraint of the form \(g(x, y)=0\text{.}\)
    🔗

    Definition 3.7.7. Method of Lagrange Multipliers.

    Suppose you want to find the absolute \(\max / \min\) values of a differentiable function \(f(x, y)\) subject to the domain restriction \(g(x, y)=0\text{.}\) If \(g(x, y)\) is a smooth curve and \(\nabla g(x, y) \neq 0\) for all points on \(g(x, y)=0\text{,}\) then we can find these absolute \(\mathrm{max} / \mathrm{min}\) values as follows:
    🔗
    1. Find values of \(x, y\text{,}\) and \(\lambda\) (called a Lagrange multiplier) such that
      \begin{equation*} \nabla f(x, y)=\lambda \nabla g(x, y) \quad \text { and } \quad g(x, y)=0\text{.} \end{equation*}
      🔗
      🔗
    2. Evaluate \(f\) at the values \((x, y)\) found in step 1 and at the endpoints of \(g(x, y)=0\text{,}\) if they exist (for example, if \(g(x, y)=0\) is a line segment).
      🔗
      🔗
    3. The largest and smallest values you found in part (b) are the absolute max and min values of \(f\text{,}\) respectively, restricted to \(g(x, y)=0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Note 3.7.8.

    When we say \(g(x, y)=0\) is smooth, we mean that it is differentiable (has no sharp edges and doesn’t intersect itself).
    🔗
    🔗

    Example 3.7.9. Examples of smooth and non smooth curves.

    Solution.
    A curve is smooth when it is differentiable everywhere: it has no sharp corners and it does not intersect itself. The circle \((x+6)^2+y^2=2\) and the parabola \(y=(x+3)^2\) are smooth curves, since at every point they have a well-defined tangent line. The graph of \(y=|x-3|\) is not smooth because of the sharp corner, where no tangent line exists. A cycloid curve is not smooth because it has a cusp.
    🔗
    🔗
    🔗

    Example 3.7.10.

    Using the method of Lagrange multipliers, find the absolute max/min values of \(f(x, y)=x^{2}-y^{2}\) subject to the constraint \(y=2x,-\frac{1}{2} \leq x \leq \frac{1}{2}\text{.}\)
    🔗
    \(f(x, y)=x^{2}-y^{2} \text { subject to the constraint } y=2,-1/2 \leq x \leq 1/2\)
    🔗
    Solution.
    We first write the constraint in the form \(g(x,y)=0\text{:}\) from \(y=2x\) we get \(g(x,y) = y - 2x = 0\text{.}\) The gradients are \(\nabla f = \langle 2x, -2y \rangle\) and \(\nabla g = \langle -2, 1 \rangle\text{,}\) so the system \(\nabla f = \lambda \nabla g\) together with the constraint reads
    \begin{equation*} 2x = -2\lambda, \quad -2y = \lambda, \quad y = 2x \end{equation*}
    The first equation gives \(\lambda = -x\text{;}\) substituting into the second gives \(-2y = -x \Rightarrow x = 2y\text{.}\) Combining with the constraint \(y=2x\) we get \(x = 2(2x) = 4x \Rightarrow 3x = 0 \Rightarrow x = 0\text{,}\) and then \(y=0\text{.}\) This gives the single candidate \((0,0)\text{.}\)
    🔗
    Since the constraint is a line segment, we must also evaluate \(f\) at its endpoints, \(x=-\frac{1}{2}\) and \(x=\frac{1}{2}\text{,}\) that is at the points \(\left( -\frac{1}{2}, -1 \right)\) and \(\left( \frac{1}{2}, 1 \right)\text{.}\) Evaluating \(f\) at all of the candidates:
    \begin{equation*} f(0,0) = 0, \quad f\left( \tfrac{1}{2}, 1 \right) = \tfrac{1}{4} - 1 = -\tfrac{3}{4}, \quad f\left( -\tfrac{1}{2}, -1 \right) = \tfrac{1}{4} - 1 = -\tfrac{3}{4} \end{equation*}
    The segment contains its endpoints and is bounded, so the Extreme Value theorem applies: the absolute maximum is \(0\) at \((0,0)\) and the absolute minimum is \(-\frac{3}{4}\text{,}\) attained at both \(\left( \frac{1}{2}, 1 \right)\) and \(\left( -\frac{1}{2}, -1 \right)\text{.}\)
    🔗
    🔗
    🔗

    Example 3.7.11.

    Find the absolute \(\mathrm{max} / \mathrm{min}\) values of the objective function \(f(x, y)= \frac{x}{5}+\frac{y}{2}\) where \(x\) and \(y\) lie on the circle \(C\) given by \(x^{2}+y^{2}=1\text{.}\)
    🔗
    \(f(x, y)=\frac{x}{5}+\frac{y}{2}\text { subject to the constraint } x^{2}+y^{2}=1\)
    🔗
    Solution 1.
    We write the constraint as \(g(x,y) = x^{2}+y^{2}-1 = 0\text{.}\) The gradients are \(\nabla f = \left\langle \frac{1}{5}, \frac{1}{2} \right\rangle\) and \(\nabla g = \langle 2x, 2y \rangle\text{,}\) so the system \(\nabla f = \lambda \nabla g\) together with the constraint reads
    \begin{equation*} \frac{1}{5} = 2\lambda x, \quad \frac{1}{2} = 2\lambda y, \quad x^{2}+y^{2} = 1 \end{equation*}
    The left sides of the first two equations are nonzero, so none of \(x\text{,}\) \(y\text{,}\) or \(\lambda\) can be zero. We may therefore solve each of the first two equations for \(\lambda\text{:}\)
    \begin{equation*} \lambda = \frac{1}{10x}, \qquad \lambda = \frac{1}{4y} \end{equation*}
    Setting these two expressions equal to each other eliminates \(\lambda\) and gives a relation between \(x\) and \(y\text{:}\)
    \begin{equation*} \frac{1}{10x} = \frac{1}{4y} \Rightarrow 4y = 10x \Rightarrow y = \frac{5}{2}x \end{equation*}
    Substituting \(y = \frac{5}{2}x\) into the constraint \(x^{2}+y^{2}=1\text{:}\)
    \begin{equation*} x^{2} + \frac{25}{4}x^{2} = 1 \Rightarrow \frac{29}{4}x^{2} = 1 \Rightarrow x^{2} = \frac{4}{29} \Rightarrow x = \pm\frac{2}{\sqrt{29}} \end{equation*}
    and the corresponding \(y = \frac{5}{2}x = \pm\frac{5}{\sqrt{29}}\text{.}\) This produces the two candidates \(\left( \frac{2}{\sqrt{29}}, \frac{5}{\sqrt{29}} \right)\) and \(\left( -\frac{2}{\sqrt{29}}, -\frac{5}{\sqrt{29}} \right)\text{.}\)
    🔗
    🔗
    Solution 2.
    It remains to evaluate \(f\) at the two candidates found in Example 3.7.11:
    \begin{gather*} f\left( \frac{2}{\sqrt{29}}, \frac{5}{\sqrt{29}} \right) = \frac{1}{5}\cdot\frac{2}{\sqrt{29}} + \frac{1}{2}\cdot\frac{5}{\sqrt{29}} = \frac{4}{10\sqrt{29}} + \frac{25}{10\sqrt{29}} = \frac{29}{10\sqrt{29}} = \frac{\sqrt{29}}{10}\\ f\left( -\frac{2}{\sqrt{29}}, -\frac{5}{\sqrt{29}} \right) = -\frac{\sqrt{29}}{10} \end{gather*}
    The circle has no endpoints and is bounded, so the Extreme Value theorem applies: the absolute maximum is \(\frac{\sqrt{29}}{10}\) at \(\left( \frac{2}{\sqrt{29}}, \frac{5}{\sqrt{29}} \right)\) and the absolute minimum is \(-\frac{\sqrt{29}}{10}\) at \(\left( -\frac{2}{\sqrt{29}}, -\frac{5}{\sqrt{29}} \right)\text{.}\)
    🔗
    🔗
    🔗

    Remark 3.7.12.

    In Example 3.7.10 and Example 3.7.11, we could see from the pictures that the values we found are the only absolute \(\mathrm{max} / \mathrm{min}\) values.
    🔗
    🔗
    In practice, how can we know if we found the correct (and only) absolute \(\mathrm{max} / \mathrm{min}\) values? We can use a theorem called the Extreme Value theorem.
    🔗

    Theorem 3.7.13. The Extreme Value Theorem.

    Let \(f(x, y)\) be differentiable and \(g(x, y)=0\) be a differentiable curve inside the domain of \(f\text{.}\) If the curve \(g(x, y)=0\) :
    🔗
    • Contains its endpoints (if they exist)
      🔗
      🔗
    • and is bounded (you can put it inside a circle of finite radius)
      🔗
      then the differentiable function \(f(x, y)\) will have absolute \(\mathrm{max} / \mathrm{min}\) values on \(g(x, y)=0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Remark 3.7.14.

    If the conditions for the Extreme Value theorem hold, then the method of Lagrange multipliers will find the absolute max/min values of \(f\) restricted to \(g(x, y)=0\text{.}\) If any of the two conditions above doesn’t hold, then the method of Lagrange multipliers will only find local extremum.
    🔗
    🔗

    Note 3.7.15. Combining Boundaries and Interiors.

    Suppose that the (differentiable) function \(f(x, y)\) is constraint by the (differentiable) curve \(g(x, y)=0\) enclosing a region \(S\) in the \(x y\)-plane (we call such curves simple and closed).
    🔗
    Then we can combine the method of Lagrange multipliers with critical point analysis to find the absolute \(\max / \min\) values of \(f\) on \(g(x, y)=0\) and \(S\text{.}\)
    🔗
    The simple and closed curve \(x^{2}+y^{2}=1\) (dark green) enclosing a region \(S\) (light green)
    🔗
    🔗

    Remark 3.7.16.

    The method is as follows:
    🔗
    • Find candidates for absolute \(\max / \min\) values on \(g(x, y)=0\) (the boundary) using the method of Lagrange multipliers.
      🔗
      🔗
    • Find candidates for absolute \(\max / \min\) values on the region \(S\) (the region enclosed by \(g(x, y)=0\text{,}\) excluding the boundary).
      🔗
      🔗
    • Evaluate \(f\) at all of these points. The largest is the absolute max and the smallest the absolute min.
      🔗
      🔗
    🔗
    Important: The Extreme Value theorem applies to regions described in the previous note (regions enclosed by a simple and closed curve \(g(x, y)=0\) including its interior).
    🔗
    🔗

    Example 3.7.17.

    Find the absolute max and min values (if they exist) of \(f(x, y)= 4 x^{2}+y^{2}+1\) restricted to \(R=\left\{(x, y) \mid x^{2}+4 y^{2} \leq 1\right\}\text{.}\)
    🔗
    Solution 1.
    The region \(R\) consists of the ellipse \(x^{2}+4y^{2}=1\) (the boundary) together with its interior, so it is a region enclosed by a simple and closed curve including its interior; the Extreme Value theorem guarantees that the absolute max/min values exist. We combine critical point analysis in the interior with the method of Lagrange multipliers on the boundary.
    🔗
    Interior. A critical point of \(f\) in the interior is a point where the gradient vanishes. Since \(\nabla f = \langle 8x,\, 2y \rangle\text{,}\) we set each component to zero:
    \begin{equation*} 8x = 0 \quad\text{and}\quad 2y = 0 \Rightarrow x = 0,\ y = 0 \end{equation*}
    The only critical point is \((0,0)\text{,}\) and it satisfies \(0^{2}+4\cdot 0^{2} = 0 \lt 1\text{,}\) so it lies strictly inside \(R\) and is a valid candidate. To classify it we apply the Second Derivative Test. The second-order partials are
    \begin{equation*} f_{xx} = 8, \quad f_{yy} = 2, \quad f_{xy} = 0 \end{equation*}
    so the discriminant is \(D = f_{xx}f_{yy} - \left( f_{xy} \right)^{2} = (8)(2) - 0^{2} = 16 \gt 0\text{.}\) Since \(D \gt 0\) and \(f_{xx} = 8 \gt 0\text{,}\) the critical point \((0,0)\) is a local minimum, with value \(f(0,0) = 1\text{.}\)
    🔗
    🔗
    Solution 2.
    Boundary. We write the constraint as \(g(x,y) = x^{2}+4y^{2}-1 = 0\text{,}\) with \(\nabla g = \langle 2x, 8y \rangle\text{.}\) The system \(\nabla f = \lambda \nabla g\) together with the constraint reads
    \begin{equation*} 8x = 2\lambda x, \quad 2y = 8\lambda y, \quad x^{2}+4y^{2} = 1 \end{equation*}
    We solve each of the first two equations for \(\lambda\text{.}\) Moving everything to one side and factoring,
    \begin{equation*} 2x(4-\lambda) = 0 \Rightarrow x = 0 \ \text{ or }\ \lambda = 4, \qquad 2y(1-4\lambda) = 0 \Rightarrow y = 0 \ \text{ or }\ \lambda = \tfrac{1}{4} \end{equation*}
    A single value of \(\lambda\) must satisfy both equations at once, but \(\lambda = 4\) and \(\lambda = \frac{1}{4}\) cannot both hold. Eliminating \(\lambda\) this way rules out \(x \neq 0\) and \(y \neq 0\) occurring together, so at least one of \(x, y\) is zero (and both cannot be zero, since \((0,0)\) does not satisfy the constraint). This leaves two cases:
    🔗
    If \(x = 0\text{,}\) the constraint gives \(4y^{2} = 1 \Rightarrow y = \pm\frac{1}{2}\text{,}\) producing the candidates \(\left( 0, \frac{1}{2} \right)\) and \(\left( 0, -\frac{1}{2} \right)\text{.}\)
    🔗
    If \(y = 0\text{,}\) the constraint gives \(x^{2} = 1 \Rightarrow x = \pm 1\text{,}\) producing the candidates \((1,0)\) and \((-1,0)\text{.}\)
    🔗
    🔗
    Solution 3.
    We now evaluate \(f\) at the interior candidate and at all of the boundary candidates:
    \begin{equation*} f(0,0) = 0 + 0 + 1 = 1, \quad f\left( 0, \pm\tfrac{1}{2} \right) = \tfrac{1}{4} + 1 = \tfrac{5}{4}, \quad f(\pm 1, 0) = 4 + 1 = 5 \end{equation*}
    Comparing the values \(1\text{,}\) \(\frac{5}{4}\text{,}\) and \(5\text{:}\) the absolute maximum of \(f\) on \(R\) is \(5\text{,}\) attained at \((1,0)\) and \((-1,0)\) on the boundary, and the absolute minimum is \(1\text{,}\) attained at the interior critical point \((0,0)\text{.}\) Note that the smallest value on the boundary, \(\frac{5}{4}\) at \(\left( 0, \pm\frac{1}{2} \right)\text{,}\) is not the absolute minimum of \(f\) on \(R\) — the minimum occurs in the interior, which is why the critical point analysis step cannot be skipped.
    🔗
    🔗
    🔗
    The method of Lagrange multipliers extends easily to higher dimensions.
    🔗

    Remark 3.7.18. Lagrange Multipliers in Higher Dimensions.

    Suppose you want to maximize or minimize the function \(f(x, y, z)\) subject to the constraint \(g(x, y, z)=0\text{.}\) Then solve the system
    \begin{align*} \nabla f(x, y, z) \amp =\lambda \nabla g(x, y, z)\\ g(x, y, z) \amp =0 \end{align*}
    🔗
    🔗

    Example 3.7.19. Example 4.44 of the book.

    Find the absolute max and min values (if they exist) of \(f(x, y, z)= x^2+y^2+z^2\) subject to the constraint \(x+y+z=1\text{.}\)(Since the restriction \(x+y+z=1\) is not a bounded set, assume that the point found with the use of the Lagrange Multipliers method must be either an absolute maximum or minimum for this example.)
    🔗
    Solution.
    We write the constraint as \(g(x,y,z) = x+y+z-1 = 0\text{.}\) The gradients are \(\nabla f = \langle 2x, 2y, 2z \rangle\) and \(\nabla g = \langle 1, 1, 1 \rangle\text{,}\) so the system \(\nabla f = \lambda \nabla g\) together with the constraint reads
    \begin{equation*} 2x = \lambda, \quad 2y = \lambda, \quad 2z = \lambda, \quad x+y+z = 1 \end{equation*}
    The first three equations give \(x = y = z = \frac{\lambda}{2}\text{.}\) Substituting into the constraint:
    \begin{equation*} x + x + x = 1 \Rightarrow 3x = 1 \Rightarrow x = y = z = \frac{1}{3} \end{equation*}
    so the only candidate is \(\left( \frac{1}{3}, \frac{1}{3}, \frac{1}{3} \right)\text{,}\) with
    \begin{equation*} f\left( \tfrac{1}{3}, \tfrac{1}{3}, \tfrac{1}{3} \right) = \tfrac{1}{9} + \tfrac{1}{9} + \tfrac{1}{9} = \tfrac{1}{3} \end{equation*}
    Since the plane \(x+y+z=1\) is not a bounded set, the Extreme Value theorem does not apply, and as stated in the problem we assume that the candidate found in Example 3.7.19 must be either an absolute maximum or an absolute minimum. To decide which, we compare with another point on the constraint, say \((1,0,0)\text{:}\)
    \begin{equation*} f(1,0,0) = 1 \gt \frac{1}{3} = f\left( \tfrac{1}{3}, \tfrac{1}{3}, \tfrac{1}{3} \right) \end{equation*}
    so \(\left( \frac{1}{3}, \frac{1}{3}, \frac{1}{3} \right)\) is the absolute minimum, with value \(\frac{1}{3}\text{.}\) There is no absolute maximum: the points \((t, -t, 1)\) lie on the plane for every value of \(t\text{,}\) and \(f(t,-t,1) = 2t^2 + 1\) becomes arbitrarily large as \(t\) grows.
    🔗
    🔗
    🔗

    Example 3.7.20. Checkpoint 4.38 of the book.

    A company has determined that its production level is given by the Cobb-Douglas function \(f(x,y)=2.5x^{0.45}y^{0.55}\) where \(x\) represents the total number of labour hours in 1 year and y represents the total capital input for the company. Suppose 1 unit of labour costs $40 and 1 unit of capital costs $50. Use the method of Lagrange multipliers to find the maximum value of \(f(x,y)=2.5x^{0.45}y^{0.55}\) subject to a budgetary constraint of $500,000 per year.
    🔗
    Solution 1.
    The total cost of \(x\) units of labour and \(y\) units of capital is \(40x+50y\) dollars, so the budgetary constraint is \(40x+50y=500,000\text{.}\) One can reasonably assume that \(x\) and \(y\) cannot be negative due to representing non-negative physical values. That in terms imply that \(x\leq 12500\) and \(y\leq 10000\text{.}\) Now with these restrictions the line segment of \(40x+50y=500,000\) is bounded.
    🔗
    We write \(40x+50y=500,000\) as \(g(x,y) = 40x+50y-500,000 = 0\text{.}\) The partial derivatives of the objective function, which exist only for the positive values of \(x\) and \(y\text{,}\) are
    \begin{gather*} f_x = 2.5(0.45)x^{-0.55}y^{0.55} = 1.125\, x^{-0.55}y^{0.55}\\ f_y = 2.5(0.55)x^{0.45}y^{-0.45} = 1.375\, x^{0.45}y^{-0.45} \end{gather*}
    so the system \(\nabla f = \lambda \nabla g\) together with the constraint reads
    \begin{equation*} 1.125\, x^{-0.55}y^{0.55} = 40\lambda, \quad 1.375\, x^{0.45}y^{-0.45} = 50\lambda, \quad 40x+50y = 500,000\text{.} \end{equation*}
    Now solving for \(\lambda\) produces the following
    \begin{gather*} \frac{1.125\, x^{-0.55}y^{0.55}}{40} = \lambda \text{ and }\frac{1.375\, x^{0.45}y^{-0.45}}{50} = \lambda \Rightarrow\\ \frac{1.125}{1.375}y = \frac{40}{50} x\Rightarrow y = \frac{1.375}{1.125} \cdot \frac{40}{50} x \Rightarrow y = \frac{11}{9} \cdot \frac{40}{50} x \Rightarrow y = \frac{44}{45}x \end{gather*}
    🔗
    🔗
    Solution 2.
    Substituting \(y = \frac{44}{45}x\) into the budgetary constraint:
    \begin{gather*} 40x + 50\cdot\frac{44}{45}x = 500,000 \Rightarrow 40x + \frac{440}{9}x = 500,000 \Rightarrow \frac{360}{9}x + \frac{440}{9}x = 500,000\\ \Rightarrow \frac{800}{9}x = 500,000 \Rightarrow x = \frac{9 \cdot 500,000}{800} = 5625 \end{gather*}
    and then
    \begin{equation*} y = \frac{44}{45}\cdot 5625 = 44 \cdot 125 = 5500 \end{equation*}
    The value of the production level at that point is \(f(5625, 5500) = 2.5\,(5625)^{0.45}(5500)^{0.55} \approx 13890\text{.}\) At the end points \((0,10000)\) and \((12500,0)\) the function takes the value \(0\text{.}\)
    🔗
    So the production level is maximized when the company uses \(5625\) labour hours and \(5500\) units of capital, and the maximum value of \(f\) subject to the budgetary constraint is
    \begin{equation*} f(5625, 5500) = 2.5\,(5625)^{0.45}(5500)^{0.55} \approx 13890 \end{equation*}
    that is, a maximum production level of approximately \(13890\) units.
