Example 3.2.22.

Find all four second-order partial derivatives of \(z= \cos(x) \ln y\text{.}\)
🔗
Solution.
We first compute the two first-order partial derivatives, treating \(y\) and \(x\) as constants respectively:
\begin{equation*} z_x = -\sin(x) \ln y, \quad z_y = \frac{\cos(x)}{y} \end{equation*}
Differentiating each of these once more, with respect to each variable:
\begin{gather*} z_{xx} = \frac{\partial}{\partial x}\left( -\sin(x) \ln y \right) = -\cos(x) \ln y\\ z_{yy} = \frac{\partial}{\partial y}\left( \frac{\cos(x)}{y} \right) = -\frac{\cos(x)}{y^2}\\ z_{xy} = \frac{\partial}{\partial y}\left( -\sin(x) \ln y \right) = -\frac{\sin(x)}{y}\\ z_{yx} = \frac{\partial}{\partial x}\left( \frac{\cos(x)}{y} \right) = -\frac{\sin(x)}{y} \end{gather*}
Note that the two mixed partial derivatives are equal, \(z_{xy} = z_{yx}\text{,}\) as expected since both are continuous functions (wherever \(y \gt 0\text{,}\) which is the domain of \(z\)).
