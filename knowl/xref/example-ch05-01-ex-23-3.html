Example 5.1.11.

Evaluate \(\int_{C} \vec{F} \cdot \vec{T} d s\) where \(\vec{F}=\langle y, -x\rangle\) on the following oriented curves in the plane:
🔗
(a) The quarter-circle \(C_{1}\) from \(P(1,0)\) to \(Q(0,1)\) (in black).
🔗
(b) The quarter-circle - \(C_{1}\) from \(Q(0,1)\) to \(P(1,0)\text{.}\)
🔗
(c) The path \(C_{2}\) from \(Q(0,1)\) to \(P(1,0)\) via two line segments through \(O(0,0)\) (in red).
🔗
Solution 1.
\begin{gather*} C_1 : \vec r (t) = \langle \cos t , \sin t \rangle , \ 0\leq t \leq \frac{\pi}{2}, \quad \vec r ' (t) = \langle -\sin t , \cos t \rangle\\ \vec F ( \vec r (t)) = \langle \sin t, - \cos t \rangle , \quad \vec F ( \vec r (t)) \cdot \vec r'(t) = -\sin^2 t + (-\cos^2 t) = -1\\ \int_{C_1} \vec F \cdot \vec T \ ds = \int_{C_1} \vec F\ d\vec r =\int_a^b \vec F ( \vec r (t)) \vec r' (t)\ dt = \int_0^{\frac{\pi}{2}} -1 \ dt =-\frac{\pi}{2} \end{gather*}

🔗
Solution 2.
b)
\begin{gather*} -C_1 : \vec r (t) = \langle \sin t , \cos t \rangle , \ 0\leq t \leq \frac{\pi}{2}, \quad \vec r ' (t) = \langle -\cos t , -\sin t \rangle\\ \vec F ( \vec r (t)) = \langle \cos t, - \sin t \rangle , \quad \vec F ( \vec r (t)) \cdot \vec r'(t) = \cos^2 t + \sin^2 t = 1\\ \int_{C_1} \vec F \cdot \vec T \ ds = \int_{C_1} \vec F\ d\vec r =\int_a^b \vec F ( \vec r (t)) \vec r' (t)\ dt = \int_0^{\frac{\pi}{2}} 1 \ dt =\frac{\pi}{2} \end{gather*}
🔗
c)
\begin{gather*} \text{Line in space: }\vec l (t) = \vec v + t \vec u ,\\ \text{ where }\vec v\text{ represents the starting point and }\vec u\text{ is a vector in the direction of the line.}\\ C_2 : \vec r (t) = \begin{cases} \langle 0,1 \rangle + t \langle 0 , -1 \rangle = \langle 0,1-t \rangle\amp\quad 0\leq t \leq 1\\ \langle 0,0 \rangle + (t-1) \langle 1 , 0 \rangle = \langle t-1, 0 \rangle\amp\quad 1\leq t \leq 2\\ \end{cases}\\ \vec r' (t) = \begin{cases} \langle 0,-1 \rangle\amp\quad 0\lt t \lt 1\\ \langle 1, 0 \rangle\amp\quad 1\lt t \lt 2\\ \end{cases}\\ \vec F ( \vec r (t)) = \begin{cases} \langle 1-t , 0\rangle\amp\quad 0\leq t \leq 1\\ \langle 0, -t+1 \rangle\amp\quad 1\leq t \leq 2\\ \end{cases}\\ \vec F ( \vec r (t)) \cdot \vec r'(t) = \begin{cases} (1-t)\cdot 0 + 0\cdot (-1) = 0\amp\quad 0\lt t \lt 1\\ 0\cdot 1 + (-t+1)\cdot 0 = 0\amp\quad 1\lt t \lt 2\\ \end{cases}\\ \int_{C_2} \vec F \cdot \vec T \ ds = \int_{C_2} \vec F\ d\vec r =\int_a^b \vec F ( \vec r (t)) \vec r' (t)\ dt + \int_b^c \vec F ( \vec r (t)) \vec r' (t)\ dt= \int_0^{1} 0 \ dt + \int_{1}^2 0 \ dt = 0 \end{gather*}
