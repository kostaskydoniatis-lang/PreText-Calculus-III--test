Example 2.2.4.

Find the domain and range of the following functions:
🔗
  1. Plane, \(f(x, y)= 4x+ y+1\)
    🔗
    🔗
  2. Paraboloid, \(f(x, y)=x^{2}+y^{2}\)
    🔗
    🔗
  3. Upper Half of a Sphere with Radius 1, \(f(x, y)=\sqrt{1-x^2 -y^{2}}\)
    🔗
    🔗
🔗
Solution 1.
Any pair \((x,y)\) can be plugged into \(4x+y+1\text{,}\) so \(\operatorname{dom}(f) = \mathbb{R}^2\text{,}\) the entire \(xy\)-plane. For the range, fixing \(y=0\) the outputs \(f(x,0) = 4x+1\) already take every real value as \(x\) varies, so \(\operatorname{rang}(f) = \mathbb{R}\text{.}\)
🔗
🔗
Solution 2.
Again any pair can be plugged in, so \(\operatorname{dom}(f) = \mathbb{R}^2\text{.}\) Since \(x^2+y^2 \geq 0\text{,}\) no negative output is possible. The output 0 is attained at \((0,0)\text{,}\) and every \(z \gt 0\) is also attained, for instance at \((\sqrt{z}, 0)\text{.}\) Hence \(\operatorname{rang}(f) = [0, \infty)\text{.}\)
🔗
🔗
Solution 3.
Here we need the expression under the square root to be non-negative:
\begin{equation*} 1-x^2-y^2 \geq 0 \Leftrightarrow x^2+y^2 \leq 1 \end{equation*}
so \(\operatorname{dom}(f)\) is the disk of radius 1 centered at the origin (including its boundary circle). The square root is non-negative, and the outputs run from \(f=0\) (attained on the boundary circle \(x^2+y^2=1\)) up to \(f=1\) (attained at \((0,0)\)), so \(\operatorname{rang}(f) = [0,1]\text{.}\)
