    Section 5.4 Green’s Theorem: 2D Divergence

    Note 5.4.1.

    Suppose you have a SCPS curve \(C\) representing a boundary enclosing a region \(R\) inside some liquid whose particles motion is given by a vector field F. As before, it makes sense that the behaviour of the liquid particles in \(R\) determines the behaviour of the particles near the boundary. For example, if for all (most) points in \(R\text{,}\) particles near them are moving outwards (away from the point), it makes sense that the same is happening near the boundary (particles are moving outwards across the boundary \(C\) ), as shown below:
    🔗
    🔗
    We quantify the expansion (outwards/repelling motion) of particles at a point using divergence.
    🔗

    Definition 5.4.2. 2D Divergence.

    Let \(\vec{F}=\langle f(x, y), g(x, y)\rangle\) be a differentiable vector field representing the motion of particles. We measure the outwards/repelling motion at a point ( \(a, b\) ) by using
    \begin{equation*} \operatorname{Div} \vec{F}(a, b)=\frac{\partial f}{\partial x}(a, b)+\frac{\partial g}{\partial y}(a, b)\text{.} \end{equation*}
    🔗
    🔗

    Note 5.4.3.

    When we say “at a point”, we really mean inside an infinitely small circle centered at \((a, b)\text{.}\)
    🔗
    🔗

    Remark 5.4.4. The sign of \(\operatorname{Div} \vec{F}(a, b)\).

    The sign of \(\operatorname{Div} \vec{F}(a, b)\) tells us whether particles are expanding or contracting at a point:
    🔗
    • If \(\operatorname{Div} \vec{F}(a, b) \gt 0,(a, b)\) is acting as a repellent (particles are moving away from \((a, b)\)).
      🔗
      🔗
    • If \(\operatorname{Div} \vec{F}(a, b) \lt 0,(a, b)\) is acting as an attractor (particles are moving towards \((a, b)\) ).
      🔗
      🔗
    • If \(\operatorname{Div} \vec{F}(a, b)=0\text{,}\) there is no discernible repellent/attractor motion around \((a, b)\) and we say \((a, b)\) is not a source.
      🔗
      🔗
    🔗
    🔗

    Example 5.4.5.

    Given the vector field \(\vec{F}(x, y)=\left\langle x^2+y^2+x, y^{2}+x^2+y\right\rangle\) :
    🔗
    (a) Compute Div F.
    🔗
    (b) Find a point that acts as an attractor and a point that acts as a repellent.
    🔗
    (c) Find a point that is not a source.
    🔗
    Solution 1.
    \begin{equation*} \operatorname{Div}\vec F = f_x + g_y = 2x+1 +2y +1 = 2x+2y+2 \end{equation*}
    🔗
    🔗
    Solution 2.
    Attractor implies \(\operatorname{Div} \vec F \lt 0 \) and repellent \(\operatorname{Div} \vec F \gt 0\)
    \begin{gather*} \operatorname{Div}\vec F \lt 0 \Rightarrow 2x+2y+2 \lt 0 \Rightarrow y \lt -1-x\\ \text{An easy point for this purpose, satisfying the above restriction is }(0,-2), \ \operatorname{Div}\vec F(0,-2) = -2\\ \operatorname{Div}\vec F \gt 0 \Rightarrow 2x+2y+2 \gt 0 \Rightarrow y \gt -1-x\\ \text{An easy point for this purpose, satisfying the above restriction is }(0,0), \ \operatorname{Div}\vec F(0,0) = 2 \end{gather*}
    🔗
    🔗
    Solution 3.
    Not a source implies zero Div.
    \begin{gather*} \operatorname{Div} \vec F = 0 \Rightarrow 2x+2y+2 = 0 \Rightarrow y = -1-x\\ \text{An easy point for this purpose, satisfying the above restriction is }(0,-1), \ \operatorname{Div}\vec F(0,-1) = 0 \end{gather*}
    🔗
    🔗
    🔗
    This relationship between expansion inside a region and its boundary is quantified mathematically by Green’s Theorem.
    🔗

    Theorem 5.4.6. Green’s Theorem: Divergence.

    Let \(C\) be a SCPS curve, oriented counterclockwise, that encloses a connected and simply connected region \(R\) in the plane. Assume that \(\vec{F}=\langle f, g\rangle\text{,}\) where \(f\) and \(g\) have continuous first partial derivatives in \(R\text{.}\) Then
    \begin{equation*} \oint_{C} \vec{F} \cdot \vec{N} d s=\iint_{R}\left(\frac{\partial f}{\partial x}+\frac{\partial g}{\partial y}\right) d A \end{equation*}
    🔗
    🔗

    Remark 5.4.7.

    Given \(\vec{F}=\langle f(x, y), g(x, y)\rangle\) and \(\vec{r}(t)=\langle x(t), y(t)\rangle\text{,}\) the following are equivalent:
    \begin{equation*} \int_{C} \vec{F} \cdot \vec{N} d s=\int_{C} f d y-g d x \end{equation*}
    🔗
    🔗

    Note 5.4.8.

    1. Since we are dealing with curl, we assume that \(C\) is simple and closed (so that it encloses a region \(R\) ).
      🔗
      🔗
    2. Important: This theorem says that in order to compute the divergence across a SCPS boundary, you add up the divergence at each point inside the enclosed region \(R\text{.}\)
      🔗
      🔗
    3. The proof of this result is simple and is given in the book.
      🔗
      🔗
    🔗
    🔗

    Example 5.4.9.

    Using Green’s theorem, compute the integral that represent the flux
    \begin{equation*} \oint_{C}2x-y d y-x^4 d x\text{,} \end{equation*}
    where \(C\) is the unit circle (oriented counter-clockwise).
    🔗
    Solution.
    From previous material \(\text{Flux} = \int_{C} \vec{F} \cdot \vec{N} d s\text{.}\) According to the above
    \begin{equation*} \int_{C} \vec{F} \cdot \vec{N} d s=\oint_{C} f d y -g d x, \ \text{for }\vec F = \langle f, g \rangle \end{equation*}
    This implies that in this case the vector field is \(\vec F = \langle 2x-y, x^4 \rangle\) whose \(\operatorname{Div} \vec F = f_x + g_y = 2 + 0 = 2\text{.}\) Additionally, from the theorem
    \begin{equation*} \int_{C} \vec{F} \cdot \vec{N} d s= \iint_R \operatorname{Div} \vec F \ dA\text{.} \end{equation*}
    Notice that both region that of integration as well as the function behave well in polar coordinates. In this coordinate system the region is expressed as \(0\leq r \leq 1\) and \(0\leq \theta \leq 2 \pi\text{,}\) while \(\operatorname{Div} \vec F (r,\theta ) = 2\text{.}\) Hence
    \begin{gather*} \iint_R \operatorname{Div} \vec F \ dA = \iint_R 2\ dA \overset{\text{Polar}}{=} \int_0^{2\pi}\int_0^1 2 r\ dr d\theta = \int_0^{2\pi} \left. r^2 \right |_0^1 d\theta =\\ \int_0^{2\pi } 1 \ d\theta = \left. \theta\right |_0^{2\pi} = 2\pi \end{gather*}
    🔗
    🔗
    🔗

    Example 5.4.10.

    Compute the flux of a fluid whose velocity field is given by \(\vec{F}= \left\langle xy, x^2\right\rangle\text{,}\) across the boundary of the region in the first quadrant bounded by the circles \(r=1, r=2\text{,}\) the line \(y=x\text{,}\) and the \(x\)-axis (oriented counter-clockwise).
    🔗
    Solution.
    Flux \(= \int_C \vec F \cdot \vec N \ ds\text{.}\) Using the previous theorem, the integral can be expressed as \(\iint_R \operatorname{Div}\vec F \ d A\text{.}\) For the vector field one has \(f(x,y) = xy\) and \(g(x,y) =x^2\text{.}\) The \(\operatorname{Div}\vec F\) of this vector field equals \(f_x+g_y= y+0 =y\text{.}\) Now in order to use Polar Coordinates one must rewrite the \(\operatorname{Div}\vec F\) and the equation \(y=x\text{.}\) Utilizing the equations \(x=r\cos \theta\) and \(y= r\sin\theta\text{,}\) one sees that \(\operatorname{Div}\vec F (r, \theta )= r\sin\theta\) and that \(y=x\) corresponds to \(\theta = \frac{\pi}{4}\) or \(\frac{5\pi}{4}\text{,}\) but the latter is not in the first quadrant.
    \begin{gather*} \iint_R \operatorname{Div}\vec F \ d A = \int_0^{\frac{\pi}{4}}\int_1^2 \operatorname{Div}\vec F (r, \theta ) r\ dr d\theta= \int_0^{\frac{\pi}{4}}\int_1^2 r \sin \theta \ r\ dr d\theta =\int_0^{\frac{\pi}{4}}\int_1^2 r^2 \sin \theta \ dr d\theta =\\ \int_0^{\frac{\pi}{4}} \left . \frac{r^3}{3} \sin \theta \right |_1^2 d\theta = \int_0^{\frac{\pi}{4}} \frac{7}{3}\sin\theta \ d\theta = \left . -\frac{7}{3}\cos\theta \right |_0^{\frac{\pi}{4}} = \frac{7}{3}\left ( - \frac{\sqrt 2}{2} +1 \right) \end{gather*}
    🔗
    🔗
    🔗

    Note 5.4.11. Stream Functions.

    As we saw in the previous section, given a vector field \(\vec{F}=\langle f, g\rangle\) defined over an open, connected, simply connected region \(R, \vec{F}\) is conservative if and only if it is irrotational. That is, \(\vec{F}\) being irrotational implies that \(\vec{F}=\nabla \varphi\text{,}\) for some potential function \(\varphi\text{.}\) Is there a similar function for source-free vector fields? Suppose that, on some open region \(R\text{,}\) we have a differentiable vector field \(\vec{F}= \langle f, g\rangle\) and that there exists a twice continuously-differentiable scalar-valued function \(\psi\) (called a stream function) such that
    \begin{equation*} \frac{\partial \psi}{\partial y}=f, \quad \frac{\partial \psi}{\partial x}=-g\text{.} \end{equation*}
    Then
    \begin{equation*} \operatorname{Div} \vec{F} =f_{x}+g_{y} =\psi_{y x}-\psi_{x y} =0 \quad(\text { since the mixed partials are equal })\text{.} \end{equation*}
    Hence, if \(\vec{F}\) has a stream function \(\psi\text{,}\) then its divergence at each point is zero. (Just as if a vector field has a potential function, its curl at each point is zero).
    🔗
    🔗

    Remark 5.4.12. Source Free and Stream Functions.

    Let \(R\) be an open, connected, simply connected region. Then \(\vec{F}\) is sourcefree on \(R\) if and only if it has a stream function on \(R\text{.}\)
    🔗
    🔗

    Example 5.4.13.

    Consider the function \(\psi=x^3 y+y^2\text{.}\) Since \(\psi_{y}=x^3+2y\) and \(\psi_{x}=3x^2y\text{,}\) we have that the vector field \(\vec{F}=\left\langle x^3+2y, -3x^2y\right\rangle\) is source-free in \(\mathbb{R}^{2}\text{.}\) Hence,
    \begin{equation*} \oint_{C} \vec{F} \cdot \vec{N} d s=0 \end{equation*}
    for all SCPS curves \(C\text{.}\)
    🔗
    Moreover, if the curve \(C\) is not closed (has starting point \(A\) and ending point \(B\) ), we have that
    \begin{equation*} \int_{C} \vec{F} \cdot \vec{N} d s=\psi(B)-\psi(A) \end{equation*}
    🔗
    🔗

    Remark 5.4.14. Summary.

    On an open, connected, simply connected region \(R\) :
    🔗
    Irrotational Field \(\vec{F}=\langle f, g\rangle\) Source-Free Field \(\vec{F}=\langle f, g\rangle\)
    curl \(\vec{F}=g_{x}-f_{y}=0\) Div \(\vec{F}=f_{x}+g_{y}=0\)
    Have \(\varphi\) with \(\nabla \varphi=\vec{F}\) Have \(\psi\) with \(\psi_{y}=f, \psi_{x}=-g\)
    \(\oint_{C} \vec{F} \cdot \vec{T} d s=0\) on all SCPS curves \(C\) \(\oint_{C} \vec{F} \cdot \vec{N} d s=0\) on all SCPS curves \(C\)
    \(\int_{C} \vec{F} \cdot \vec{T} d s=\varphi(B)-\varphi(A)\) \(\int_{C} \vec{F} \cdot \vec{N} d s=\psi(B)-\psi(A)\)
