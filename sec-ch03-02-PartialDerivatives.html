    Section 3.2 Partial Derivatives of Scalar-Valued Functions

    Note 3.2.1.

    Defining the derivative of a vector-valued function was simple because we only had one input variable (as in Calculus I).
    🔗
    If we want to define a similar concept for functions of the form \(z=f(x, y)\text{,}\) we can do it by remembering that derivatives represent rates of change.
    🔗
    🔗

    Remark 3.2.2.

    Given a function \(f(x)\text{,}\) we know that
    \begin{equation*} f^{\prime}(a)=\lim _{h \rightarrow 0} \frac{f(a+h)-f(a)}{h} \end{equation*}
    represents:
    🔗
    • The slope of the tangent line to the graph of \(f\) at the point \((a, f(a))\text{.}\)
      🔗
      🔗
    • The rate of change of \(f\) at \(x=a\) in the direction of the positive \(x\)-axis.
      🔗
      🔗
    🔗
    Above we see the graph of \(f(x)\) (red) and its tangent line at \((a, f(a))\) (blue).
    🔗
    We build up on this definition and define the rate of change of \(z=f(x, y)\text{,}\) at the input ( \(a, b\) ), in the direction of the positive \(x\)-axis, as
    \begin{equation*} \frac{\partial f}{\partial x}(a, b)=\lim _{h \rightarrow 0} \frac{f(a+h, b)-f(a, b)}{h}\text{.} \end{equation*}
    🔗
    Note that the change is happening in the \(\mathbf{x}\)-coordinate, and we leave the \(\mathbf{y}\) coordinate unchanged.
    🔗
    🔗

    Example 3.2.3.

    Find the rate of change of \(f=x^{3}+y^{2}\text{,}\) at the input \((1,1)\text{,}\) in the direction of the positive \(y\)-axis.
    🔗
    Solution.
    The rate of change of \(f\) at the input \((1,1)\) in the direction of the positive \(y\)-axis is found just like the rate of change in the direction of the positive \(x\)-axis, except now the change happens in the \(y\)-coordinate and we leave the \(x\)-coordinate unchanged. Using the corresponding limit:
    \begin{gather*} \frac{\partial f}{\partial y}(1,1) = \lim_{h \to 0} \frac{f(1, 1+h)-f(1,1)}{h} = \lim_{h \to 0} \frac{\left[ 1^3 + (1+h)^2 \right] - \left[ 1^3 + 1^2 \right]}{h}\\ = \lim_{h \to 0} \frac{1 + 1 + 2h + h^2 - 2}{h} = \lim_{h \to 0} \frac{2h + h^2}{h} = \lim_{h \to 0} \left( 2 + h \right) = 2 \end{gather*}
    So at the input \((1,1)\text{,}\) the function \(f\) increases at a rate of 2 units per unit of change in \(y\text{.}\)
    🔗
    🔗
    🔗

    Note 3.2.4.

    Since in our definition of \(\frac{\partial f}{\partial x}(a, b)\text{,}\) the \(y\)-coordinate is kept constant at \(y=b\text{,}\) we can interpret this geometrically as intersecting the surface \(z=f(x, y)\) with the plane \(y=b\) to get the level curve \(f(x, b)\text{.}\)
    🔗
    🔗

    Example 3.2.5.

    Suppose we have the surface \(f=\sin (x+y)\cos (y-x)\) and that we want to compute \(\frac{\partial f}{\partial x}(0,0)\text{.}\) Below is a picture of this surface intersected with the plane \(y=0\text{.}\)
    🔗
    When we compute \(\frac{\partial f}{\partial x}(0,0)\text{,}\) geometrically, we are computing the slope of the tangent line to the curve \(f(x, 0)\) at the input \((0,0)\text{,}\) as shown below:
    🔗
    Above we see the curve \(f(x, 0)\) and the tangent line at \((0,0, f(0,0))\)
    🔗
    🔗
    We summarize all of this information below.
    🔗

    Definition 3.2.6. Partial Derivative with Respect to \(x\).

    Given a scalar-valued function \(z=f(x, y)\text{,}\) its partial derivative with respect to \(x\) at the input \((a, b)\) (or at the point \((a, b, f(a, b))\) is defined as
    \begin{equation*} \frac{\partial f}{\partial x}(a, b)=f_{x}(a, b)=\lim _{h \rightarrow 0} \frac{f(a+h, b)-f(a, b)}{h}\text{.} \end{equation*}
    🔗
    We interpret \(f_{x}(a, b)\) as:
    🔗
    • The slope of the tangent line to the curve \(f(x, b)\) at the point \((a, b, f(a, b))\text{.}\)
      🔗
      🔗
    • The rate of change of \(f\) at the input \((a, b)\) in the direction of the positive \(x\)-axis.
      🔗
      🔗
    🔗
    🔗

    Note 3.2.7.

    We have a similar definition for \(f_{y}(a, b)\) with a similar geometric interpretation.
    🔗
    🔗

    Definition 3.2.8. Partial Derivative with Respect to \(y\).

    Given a scalar-valued function \(z=f(x, y)\text{,}\) its partial derivative with respect to \(y\) at the input \((a, b)\) (or at the point \((a, b, f(a, b))\) is defined as
    \begin{equation*} \frac{\partial f}{\partial y}(a, b)=f_{y}(a, b)=\lim _{h \rightarrow 0} \frac{f(a, b+h)-f(a, b)}{h} \end{equation*}
    🔗
    We interpret \(f_{y}(a, b)\) as:
    🔗
    • The slope of the tangent line to the curve \(f(a, y)\) at the point \((a, b, f(a, b))\text{.}\)
      🔗
      🔗
    • The rate of change of \(f\) at the input \((a, b)\) in the direction of the positive \(y\)-axis.
      🔗
      🔗
    🔗
    🔗
    The graphs above show only the plots; you can drag and zoom them. To see the expressions behind them, or to save a copy and create your own version of the graphs, open them in a new page from here: link to the left graph, link to the right graph
    🔗

    Remark 3.2.9.

    It is important we use proper notation when working with partial derivatives. Make sure to use the “partial” symbol and always refer to it as a partial derivative (not just a derivative).
    🔗
    🔗

    Note 3.2.10. Computing Partial Derivatives.

    As is expected, we don’t need to use limits every time we want to compute partial derivatives.
    🔗
    🔗

    Definition 3.2.11. Partial Derivatives (Computational).

    Given a scalar-valued function \(z=f(x, y)\text{,}\) to compute \(f_{x}\text{,}\) take (algorithmically) the “usual” derivative of \(f(x, y)\) with respect to \(x\) whilst treating the variable \(y\) as a constant. (Similarly for \(f_{y}\) ).
    🔗
    🔗

    Example 3.2.12.

    Given \(f(x, y)=(x+y)^2-e^y\text{,}\) compute
    🔗
    (a) \(f_{x}\text{.}\)
    🔗
    (b) \(f_{y}\text{.}\)
    🔗
    Solution 1.
    Treating \(y\) as a constant, the term \(e^y\) contains no \(x\) at all, so from the point of view of \(x\) it is just a fixed number (for example, if \(y\) were held at \(y=1\text{,}\) then \(e^y = e^1 = e \approx 2.718\text{,}\) a constant). The derivative of any constant is 0, so
    \begin{equation*} \frac{\partial}{\partial x}\left( e^y \right) = 0\text{.} \end{equation*}
    The term \((x+y)^2\) does depend on \(x\) and is differentiated using the (single-variable) chain rule, treating \(y\) as a constant. Putting the two pieces together:
    \begin{equation*} f_x(x,y) = 2(x+y) \cdot \frac{\partial}{\partial x}(x+y) - \frac{\partial}{\partial x}\left( e^y \right) = 2(x+y)\cdot 1 - 0 = 2(x+y) \end{equation*}
    🔗
    🔗
    Solution 2.
    Treating \(x\) as a constant, both terms now depend on \(y\text{:}\)
    \begin{equation*} f_y(x,y) = 2(x+y) \cdot \frac{\partial}{\partial y}(x+y) - e^y = 2(x+y) - e^y \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.13.

    Given \(f(x, y)=\ln (x^4y^2+1)\text{,}\) compute
    🔗
    (a) \(f_{x}\text{.}\)
    🔗
    (b) \(f_{y}\text{.}\)
    🔗
    Solution 1.
    Treating \(y\) as a constant and using the chain rule with outer function \(\ln\text{:}\)
    \begin{equation*} f_x(x,y) = \frac{1}{x^4y^2+1} \cdot \frac{\partial}{\partial x}\left( x^4y^2+1 \right) = \frac{4x^3y^2}{x^4y^2+1} \end{equation*}
    🔗
    🔗
    Solution 2.
    Treating \(x\) as a constant:
    \begin{equation*} f_y(x,y) = \frac{1}{x^4y^2+1} \cdot \frac{\partial}{\partial y}\left( x^4y^2+1 \right) = \frac{2x^4y}{x^4y^2+1} \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.14.

    Consider the Cobb-Douglas Production function (L=labor, K = capital):
    \begin{equation*} P(L,K)= 10L^{0.9}K^{0.1} \end{equation*}
    🔗
    1)Find the marginal productivity of labor and marginal productivity of capital when 20 units of labor and 10 units of capital are invested.
    🔗
    2) For this value of \(L\) is this Cobb-Douglas Production function an increasing or decreasing function of \(K\)
    🔗
    3) For this value of \(k\) is this Cobb-Douglas Production function an increasing or decreasing function of \(L\)
    🔗
    Solution 1.
    The marginal productivity of labor is the partial derivative \(P_L\) and the marginal productivity of capital is the partial derivative \(P_K\text{.}\) Treating \(K\) and \(L\) as constants respectively:
    \begin{gather*} P_L(L,K) = 10(0.9)L^{-0.1}K^{0.1} = 9L^{-0.1}K^{0.1}\\ P_K(L,K) = 10(0.1)L^{0.9}K^{-0.9} = L^{0.9}K^{-0.9} \end{gather*}
    Evaluating at the input \((L,K) = (20,10)\text{:}\)
    \begin{gather*} P_L(20,10) = 9(20)^{-0.1}(10)^{0.1} = 9\left( \frac{10}{20} \right)^{0.1} = \frac{9}{2^{0.1}} \approx 8.40\\ P_K(20,10) = (20)^{0.9}(10)^{-0.9} = \left( \frac{20}{10} \right)^{0.9} = 2^{0.9} \approx 1.87 \end{gather*}
    So at this investment level, one additional unit of labor increases production by approximately 8.40 units, while one additional unit of capital increases production by approximately 1.87 units.
    🔗
    🔗
    Solution 2.
    The rate of change of \(P\) with respect to \(K\) is \(P_K = L^{0.9}K^{-0.9}\text{,}\) which for \(L=20\) is \(P_K = (20)^{0.9}K^{-0.9} \gt 0\) for every \(K \gt 0\) (in particular \(P_K(20,10) = 2^{0.9} \approx 1.87 \gt 0\)). Since the partial derivative with respect to \(K\) is positive, the production function is an increasing function of \(K\text{.}\)
    🔗
    🔗
    Solution 3.
    The rate of change of \(P\) with respect to \(L\) is \(P_L = 9L^{-0.1}K^{0.1}\text{,}\) which for \(K=10\) is \(P_L = 9(10)^{0.1}L^{-0.1} \gt 0\) for every \(L \gt 0\) (in particular \(P_L(20,10) \approx 8.40 \gt 0\)). Since the partial derivative with respect to \(L\) is positive, the production function is an increasing function of \(L\text{.}\)
    🔗
    🔗
    🔗

    Example 3.2.15.

    Given \(f(x, y)= x^{3} \sqrt y\text{,}\) what would be the approximate effect on \(f\) of increasing \(x\) from 2 to 3 while keeping \(y\) fixed at 25 units? What about decreasing \(y\) from 25 to 24 units while keeping \(x\) fixed at 2 units?
    🔗
    Solution.
    For the first change we keep \(y\) fixed at 25 and increase \(x\) by \(\Delta x = 1\text{,}\) so we use the approximation \(f(a+\Delta x, b) - f(a,b) \approx f_x(a,b) \Delta x\text{.}\) Treating \(y\) as a constant, \(f_x = 3x^2\sqrt{y}\text{,}\) so
    \begin{equation*} f_x(2,25) = 3(2)^2\sqrt{25} = 3(4)(5) = 60 \Rightarrow f(3,25) - f(2,25) \approx 60(1) = 60 \end{equation*}
    and the approximate effect is an increase of about 60 units in \(f\text{.}\) For the second change we keep \(x\) fixed at 2 and decrease \(y\) by \(\Delta y = -1\text{,}\) so we use \(f(a, b+\Delta y) - f(a,b) \approx f_y(a,b) \Delta y\text{.}\) Treating \(x\) as a constant, \(f_y = \frac{x^3}{2\sqrt{y}}\text{,}\) so
    \begin{equation*} f_y(2,25) = \frac{2^3}{2\sqrt{25}} = \frac{8}{10} = 0.8 \Rightarrow f(2,24) - f(2,25) \approx 0.8(-1) = -0.8 \end{equation*}
    and the approximate effect is a decrease of about 0.8 units in \(f\text{.}\)
    🔗
    🔗
    🔗

    Note 3.2.16. Differentiability.

    We can talk about a function \(f(x, y)\) being differentiable at an input \((a, b)\text{.}\) However, it isn’t as easy as just saying that \(f_{x}(a, b)\) and \(f_{y}(a, b)\) exist.
    🔗
    🔗

    Definition 3.2.17. Differentiability.

    A function \(f(x, y)\) is differentiable at the input \((a, b)\) provided that \(f_{x}(a, b)\) and \(f_{y}(a, b)\) exist and that
    \begin{equation*} f(x, y)=f(a, b)+f_{x}(a, b)(x-a)+f_{y}(a, b)(y-b)+E(x, y) \end{equation*}
    where \(E(x, y)\) approaches 0 as \(x\) approaches \(a\) and \(y\) approaches \(b\text{.}\)
    🔗
    🔗

    Remark 3.2.18.

    Geometrically, this means that \(f(x, y)\) is differentiable at the input \((a, b)\) if as you zoom into the point ( \(a, b, f(a, b)\) ), the graph of \(f\) looks like a plane (is smooth).
    🔗
    🔗

    Example 3.2.19.

    Consider the surface
    \begin{equation*} f(x, y)= \begin{cases}\frac{xy}{x^2+y^2} \amp (x,y)\not = (0,0) \\ 0, \amp (x,y) = (0,0) \end{cases} \end{equation*}
    🔗
    You can verify that \(f_{x}(0,0)=f_{y}(0,0)=0\) (they exist), but \(f(x, y)\) is not differentiable at \((0,0)\text{.}\)
    🔗
    Solution.
    We first verify that both partial derivatives exist at \((0,0)\) using the limit definitions. Along the \(x\)-axis (\(y=0\)) the function is \(f(h,0) = \frac{h \cdot 0}{h^2+0^2} = 0\) for every \(h \neq 0\text{,}\) so
    \begin{equation*} f_x(0,0) = \lim_{h \to 0} \frac{f(h,0)-f(0,0)}{h} = \lim_{h \to 0} \frac{0-0}{h} = 0 \end{equation*}
    and similarly along the \(y\)-axis (\(x=0\)) we have \(f(0,h) = 0\text{,}\) so \(f_y(0,0) = 0\text{.}\) Both partial derivatives exist.
    🔗
    Now suppose \(f\) were differentiable at \((0,0)\text{.}\) Then the error term
    \begin{equation*} E(x,y) = f(x,y) - f(0,0) - f_x(0,0)(x-0) - f_y(0,0)(y-0) = f(x,y) \end{equation*}
    would have to approach 0 as \(x\) approaches 0 and \(y\) approaches 0. But if we approach the origin along the line \(y=x\text{,}\) then for every \(x \neq 0\)
    \begin{equation*} E(x,x) = f(x,x) = \frac{x \cdot x}{x^2+x^2} = \frac{x^2}{2x^2} = \frac{1}{2} \end{equation*}
    which does not approach 0. Hence \(f\) is not differentiable at \((0,0)\text{.}\) This matches the picture below: no matter how far we zoom in at the origin, the graph never flattens out to look like a plane.
    🔗
    🔗
    🔗

    Note 3.2.20.

    As with traditional derivatives, you can compute partial derivatives multiple times (even with respect to different variables).
    🔗
    🔗

    Remark 3.2.21. Second-Order Partial Derivatives.

    Below is a list of the four second-order partial derivatives of a function \(f\) and how we represent them symbolically:
    \begin{align*} \frac{\partial}{\partial x}\left(\frac{\partial f}{\partial x}\right) \amp =\frac{\partial^{2} f}{\partial x^{2}}=f_{x x}\\ \frac{\partial}{\partial y}\left(\frac{\partial f}{\partial y}\right) \amp =\frac{\partial^{2} f}{\partial y^{2}}=f_{y y}\\ \frac{\partial}{\partial y}\left(\frac{\partial f}{\partial x}\right) \amp =\frac{\partial^{2} f}{\partial y \partial x}=f_{x y}\\ \frac{\partial}{\partial x}\left(\frac{\partial f}{\partial y}\right) \amp =\frac{\partial^{2} f}{\partial x \partial y}=f_{y x} \end{align*}
    🔗
    🔗

    Example 3.2.22.

    Find all four second-order partial derivatives of \(z= \cos(x) \ln y\text{.}\)
    🔗
    Solution.
    We first compute the two first-order partial derivatives, treating \(y\) and \(x\) as constants respectively:
    \begin{equation*} z_x = -\sin(x) \ln y, \quad z_y = \frac{\cos(x)}{y} \end{equation*}
    Differentiating each of these once more, with respect to each variable:
    \begin{gather*} z_{xx} = \frac{\partial}{\partial x}\left( -\sin(x) \ln y \right) = -\cos(x) \ln y\\ z_{yy} = \frac{\partial}{\partial y}\left( \frac{\cos(x)}{y} \right) = -\frac{\cos(x)}{y^2}\\ z_{xy} = \frac{\partial}{\partial y}\left( -\sin(x) \ln y \right) = -\frac{\sin(x)}{y}\\ z_{yx} = \frac{\partial}{\partial x}\left( \frac{\cos(x)}{y} \right) = -\frac{\sin(x)}{y} \end{gather*}
    Note that the two mixed partial derivatives are equal, \(z_{xy} = z_{yx}\text{,}\) as expected since both are continuous functions (wherever \(y \gt 0\text{,}\) which is the domain of \(z\)).
    🔗
    🔗
    🔗

    Note 3.2.23.

    Note that in Example 3.2.22, \(z_{x y}=z_{y x}\text{.}\) This isn’t always the case, but it is the case if \(z_{x y}\) and \(z_{y x}\) are continuous functions.
