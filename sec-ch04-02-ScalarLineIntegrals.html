    Section 4.2 Scalar Line Integrals

    Note 4.2.1.

    As we saw in Calculus I, given an integrable function \(p(x), \int_{a}^{b} p(x) d x\) calculates the net area bounded by \(p(x)\) and the \(x\)-axis on \([a, b]\text{.}\)
    🔗
    In this section, we will find a way to find the net area bounded by a surface \(f(x, y)\) and the \(x y\)-plane, restricted to a curve \(\vec{r}(t)\) in its domain.
    🔗
    🔗

    Example 4.2.2.

    Below you can see the net area (in light green) bounded by the surface \(f(x, y)=y^2\cos x\) (in purple), restricted to the curve \(y=\sqrt{1-x^{2}}-2\) (in blue).
    🔗
    🔗

    Note 4.2.3.

    You can interpret this as finding the net area of a wall with height given by \(f(x, y)\text{.}\)
    🔗
    🔗

    Remark 4.2.4. Arc Length as a Function.

    Suppose you have an integrable curve \(\vec{r}(t)=\langle f(t), g(t)\rangle\) on \([a, b]\) (that is traversed only once). For any \(a \lt t \leq b\text{,}\) we can calculate the arc length of the curve on \([a, t]\) using the formula
    \begin{equation} s(t)=\int_{a}^{t}\left|\vec{r}^{\prime}(\tau)\right| d \tau\tag{4.2.1} \end{equation}
    🔗
    Moreover, by the Fundamental Theorem of Calculus, we have that
    \begin{equation} s^{\prime}(t)=\frac{d s}{d t}=\frac{d}{d t}\left(\int_{a}^{t}\left|\vec{r}^{\prime}(\tau)\right| d \tau\right)=\left|r^{\prime}(t)\right|\text{.}\tag{4.2.2} \end{equation}
    🔗
    Equivalently,
    \begin{equation} d s=\left|\vec{r}^{\prime}(t)\right| d t\text{.}\tag{4.2.3} \end{equation}
    🔗
    🔗
    Equation (4.2.3) is what we call the arc length differential.
    🔗
    Now, we are ready to find the net area bounded by \(f(x, y)\) and the \(x y\)-plane restricted to the curve \(\vec{r}(t)\text{.}\)
    🔗
    We will do the same thing we did in Calculus I: we will find the net area by adding net areas of rectangles and taking a limit at the end.
    🔗
    The graphs above show only the plots; you can drag and zoom them. To see the expressions behind them, or to save a copy and create your own version of the graphs, open them in a new page from here: link to the left graph, link to the middle graph, link to the right graph
    🔗
    The first thing we do is partition the curve \(\vec{r}(t)\) into \(n\) pieces. Each piece will correspond to the base of a rectangle.
    🔗
    The curve \(\vec{r}(t)\) (in blue) partitioned into \(n\) pieces of length \(\Delta s_{i}\) (from OpenStax Vol 3)
    🔗
    Each rectangle has base length \(\Delta s_{k}\) and height \(f\left(x\left(t_{k}\right), y\left(t_{k}\right)\right)\text{,}\) where \(\left(x\left(t_{k}\right), y\left(t_{k}\right)\right)\) is a point on the \(k\)-th piece of the \(\vec{r}(t)\text{.}\)
    🔗
    Hence, an approximation for the net area is given by
    \begin{equation*} \sum_{k=1}^{n} f\left(x\left(t_{k}\right), y\left(t_{k}\right)\right) \Delta s_{k}\text{.} \end{equation*}
    🔗
    Finally, as we saw in the picture above (and know from Calculus I), if we let \(n\) approach infinity (the number of rectangles), the approximation will improve. Hence, if
    \begin{equation*} \lim _{n \rightarrow \infty} \sum_{k=1}^{n} f\left(x\left(t_{k}\right), y\left(t_{k}\right)\right) \Delta s_{k} \end{equation*}
    exists, this is how we define the net area and we call this infinite sum a line integral.
    🔗

    Definition 4.2.5. Scalar Line Integral.

    Suppose you have a surface \(f(x, y)\) defined on a smooth curve \(C\) given by \(\vec{r}(t)=\langle x(t), y(t)\rangle, a \leq t \leq b\text{.}\) The line integral of \(f\) over \(C\) is
    \begin{equation*} \lim _{n \rightarrow \infty} \sum_{k=1}^{n} f\left(x\left(t_{k}\right), y\left(t_{k}\right)\right) \Delta s_{k}=\int_{C} f(x(t), y(t)) d s \end{equation*}
    provided that the limit exists. If the limit exists, we say that \(f\) is integrable on \(C\text{.}\)
    🔗
    🔗

    Note 4.2.6.

    As in previous examples, \(\vec{r}(t)\) being smooth means that it is differentiable (has no sharp edges and doesn’t cross/intersect itself).
    🔗
    From our work in the first remark, we know that \(d s=\left|\vec{r}^{\prime}(t)\right| d t\text{,}\) hence, we have that
    \begin{equation*} \int_{C} f(x(t), y(t)) d s=\int_{a}^{b} f(x(t), y(t))\left|\vec{r}^{\prime}(t)\right| d t \end{equation*}
    🔗
    🔗

    Remark 4.2.7. Evaluating Line Integrals.

    Let \(f(x, y)\) be continuous on a region containing a smooth curve \(C\) given by \(\vec{r}(t)=\langle x(t), y(t)\rangle, a \leq t \leq b\text{.}\) Then
    \begin{align*} \int_{C} f d s \amp =\int_{a}^{b} f(x(t), y(t))\left|\vec{r}^{\prime}(t)\right| d t\\ \amp =\int_{a}^{b} f(x(t), y(t)) \sqrt{x^{\prime}(t)^{2}+y^{\prime}(t)^{2}} d t \end{align*}
    🔗
    🔗

    Example 4.2.8.

    Evaluate the line integral \(\int_{C} x y d s\text{,}\) where \(C\) is the quarter circle \(\vec{r}(t)=\langle \cos (t), \sin (t)\rangle, 0 \leq t \leq \frac{\pi}{2}\text{.}\)
    🔗
    Net area bounded by \(f(x, y)\) and the \(x y\)-plane, restricted to \(\vec{r}(t)\)
    🔗
    Solution.
    For \(\vec{r}(t) = \langle \cos t, \sin t\rangle\) we have \(x(t)=\cos t\) and \(y(t)=\sin t\text{,}\) so \(\vec{r}'(t) = \langle -\sin t, \cos t\rangle\) and
    \begin{equation*} |\vec{r}'(t)| = \sqrt{(-\sin t)^2 + (\cos t)^2} = \sqrt{\sin^2 t + \cos^2 t} = 1\text{,} \end{equation*}
    so \(ds = |\vec{r}'(t)|\, dt = dt\text{.}\) Substituting \(x(t)\text{,}\) \(y(t)\text{,}\) and \(ds\) into the line integral gives
    \begin{gather*} \int_{C} xy\, ds = \int_0^{\pi/2} \cos t \sin t\, dt =\\ u=\sin t,\quad du = \cos t\, dt, \quad t=0 \Rightarrow u=0, \quad t=\frac{\pi}{2} \Rightarrow u=1\\ \int_0^1 u\, du = \left. \frac{u^2}{2}\right|_0^1 = \frac{1}{2}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Note 4.2.9.

    To parametrize a line segment starting at the point \(P\) and ending at the point \(Q\text{,}\) you can use the parametrization
    \begin{equation*} P(1-t)+Q t, \quad 0 \leq t \leq 1\text{.} \end{equation*}
    🔗
    🔗

    Example 4.2.10.

    Evaluate the line integral \(\int_{C}\left(x^{2}-y^{2}\right) d s\text{,}\) where \(C\) is the line segment from \((2,0)\) to \((0,1)\text{.}\)
    🔗
    Net area bounded by \(f(x, y)\) and the \(x y\)-plane, restricted to \(\vec{r}(t)\)
    🔗
    Solution.
    The line segment from \(P=(2,0)\) to \(Q=(0,1)\) can be parametrized as
    \begin{equation*} \vec{r}(t) = \langle 2,0\rangle + t\langle -2,1\rangle = \langle 2-2t,\, t\rangle, \ 0\leq t \leq 1, \ \vec{r}'(t) = \langle -2,1\rangle\text{,} \end{equation*}
    so \(x(t)=2-2t\) and \(y(t)=t\text{.}\) Then
    \begin{equation*} |\vec{r}'(t)| = \sqrt{(-2)^2+1^2} = \sqrt{5}\text{,} \end{equation*}
    so \(ds = \sqrt{5}\, dt\text{.}\) Since
    \begin{equation*} x(t)^2 - y(t)^2 = (2-2t)^2 - t^2 = 4-8t+4t^2-t^2 = 4-8t+3t^2\text{,} \end{equation*}
    the line integral becomes
    \begin{equation*} \int_{C}(x^2-y^2)\, ds = \sqrt{5}\int_0^1 (4-8t+3t^2)\, dt = \sqrt{5}\left. \left(4t-4t^2+t^3\right)\right|_0^1 = \sqrt{5}(4-4+1) = \sqrt{5}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Note 4.2.11.

    In Example 4.2.8 we see that part of the area is below the \(x y\)-plane. This area is still being added, but as a negative number.
    🔗
    Hence, if \(\int_{C} f d s \gt 0\text{,}\) it doesn’t mean that all of the area is above the \(x y\)-plane when restricted to \(C\text{,}\) it just means that most of the area is above the \(x y\)-plane.
    🔗
    🔗
    When computing line integrals, it doesn’t matter how you parametrize the curve \(C\text{.}\)
    🔗

    Remark 4.2.12. Independence of Parametrization.

    Let \(f(x, y)\) be continuous on a region containing a smooth curve \(C\text{.}\) Then the value of \(\int_{C} f d s\) is the same, no matter what parametrization you use for \(C\text{.}\)
    🔗
    🔗

    Example 4.2.13.

    Verify that \(\int_{C}\left(x^{2}-y^{2}\right) d s\text{,}\) where \(C\) is the line segment from \((2,0)\) to \((0,1)\text{,}\) has the same value as in Example 4.2.10 if you parametrize \(C\) as \(\vec{r}(t)=\langle -4t^2+2, 2t^2\rangle,0 \leq t \leq \frac{\sqrt 2}{2}\text{.}\)
    🔗
    Solution.
    For \(\vec{r}(t) = \langle -4t^2+2, 2t^2\rangle\) we have \(x(t)=2-4t^2\) and \(y(t)=2t^2\text{;}\) at \(t=0\) this gives \((2,0)\) and at \(t=\frac{\sqrt2}{2}\) it gives \((0,1)\text{,}\) so \(\vec{r}(t)\) traces the same line segment \(C\) as in Example 4.2.10. Differentiating, \(\vec{r}'(t) = \langle -8t, 4t\rangle\text{,}\) so
    \begin{equation*} |\vec{r}'(t)| = \sqrt{(-8t)^2+(4t)^2} = \sqrt{80t^2} = 4\sqrt{5}\,|t| = 4\sqrt{5}\,t\text{,} \end{equation*}
    since \(t\geq 0\) on \(\left[0,\frac{\sqrt2}{2}\right]\text{.}\) Hence \(ds = 4\sqrt{5}\,t\, dt\text{.}\) Since
    \begin{equation*} x(t)^2-y(t)^2 = (2-4t^2)^2 - (2t^2)^2 = 4-16t^2+16t^4-4t^4 = 4-16t^2+12t^4\text{,} \end{equation*}
    the line integral becomes
    \begin{equation*} \int_{C}(x^2-y^2)\, ds = \int_0^{\sqrt2/2} (4-16t^2+12t^4)(4\sqrt{5}\,t)\, dt = 4\sqrt{5}\int_0^{\sqrt2/2} \left(4t-16t^3+12t^5\right) dt\text{.} \end{equation*}
    Evaluating the antiderivative:
    \begin{equation*} 4\sqrt{5}\left. \left(2t^2-4t^4+2t^6\right)\right|_0^{\sqrt2/2} = 4\sqrt{5}\left(2\cdot\frac{1}{2} - 4\cdot\frac{1}{4} + 2\cdot\frac{1}{8}\right) = 4\sqrt{5}\left(1-1+\frac{1}{4}\right) = 4\sqrt{5}\cdot\frac{1}{4} = \sqrt{5}\text{,} \end{equation*}
    which matches the value found in Example 4.2.10, exactly as guaranteed by the Independence of Parametrization.
