    Section 4.9 Triple Integrals

    We will now discuss the last two change of coordinates we will see in this class: cylindrical and spherical coordinates.
    🔗

    Note 4.9.1.

    Any point in \(x y z\)-space can be expressed in the form ( \(r, \theta, z\) ) for \(r \geq 0\text{,}\) \(0 \leq \theta \leq 2 \pi\text{,}\) and \(-\infty \lt z \lt \infty\) as shown below:
    🔗
    🔗

    Note 4.9.2.

    Cylindrical coordinates can simplify triple integrals in which the 3D region of integration is easily described in these coordinates. Below are a few examples of such regions:
    🔗
    🔗

    Remark 4.9.3. Formulas to Change from Cartesian to Cylindrical Coordinates.

    Given a point ( \(x, y, z\) ) in 3-dimensional space, you can write it in cylindrical coordinates by using the formulas:
    🔗
    • \(\displaystyle r^{2}=x^{2}+y^{2}\)
      🔗
      🔗
    • \(\displaystyle \tan (\theta)=\frac{y}{x}, x \neq 0\)
      🔗
      🔗
    • \(\displaystyle z=z\)
      🔗
      🔗
    🔗
    Given a point ( \(r, \theta, z\) ) in 3-dimensional space, you can write it in Cartesian coordinates by using the formulas:
    🔗
    • \(\displaystyle x=r \cos (\theta)\)
      🔗
      🔗
    • \(\displaystyle y=r \sin (\theta)\)
      🔗
      🔗
    • \(z=z\text{.}\)
      🔗
      🔗
    🔗
    🔗
    In practice, using cylindrical coordinates translates to evaluating the double integral of a triple integral using polar coordinates.
    🔗

    Remark 4.9.4. Writing a Triple Integral in Cylindrical Coordinates.

    To set up an iterated integral in cylindrical coordinates:
    🔗
    1. Use the order \(d z d r d \theta\text{.}\)
      🔗
      🔗
    2. Find the bounds with respect to \(z\) as we did in cartesian coordinates.
      🔗
      🔗
    3. Project the 3 -dimensional region of integration \(D\) into the \(x y\) plane to get a 2 -dimensional region \(R\text{.}\)
      🔗
      🔗
    4. Set up the bounds of integration for \(r\) and \(\theta\) as if you were finding the area of \(R\text{.}\)
      🔗
      🔗
    5. The iterated integral should have the form
      \begin{equation*} \int_{\alpha}^{\beta} \int_{g(\theta)}^{h(\theta)} \int_{G(r, \theta)}^{H(r, \theta)} f(r \cos (\theta), r \sin (\theta), z) r d z d r d \theta \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Note 4.9.5. Spherical Coordinates.

    Any point in \(x y z\)-space can be expressed in the form ( \(\rho, \varphi, \theta\) ) for \(\rho \geq 0\text{,}\) \(0 \leq \varphi \leq \pi\text{,}\) and \(0 \leq \theta \leq 2 \pi\) as shown below:
    🔗
    🔗

    Remark 4.9.6.

    The angle \(\theta\) is the same as in cylindrical coordinates (rotates 0 to \(2 \pi\) in the \(x y\)-plane). The variable \(\rho\) represents the radius of a sphere.
    🔗
    However, the angle \(\varphi\) starts at the positive \(z\)-axis and rotates \(\pi\) radians ending at the negative \(z\)-axis.
    🔗
    🔗

    Note 4.9.7.

    Spherical coordinates can simplify triple integrals in which the 3D region of integration is easily described in these coordinates. Below are a few examples of such regions:
    🔗
    🔗

    Remark 4.9.8. Formulas to Change from Cartesian to Spherical Coordinates.

    Given a point ( \(x, y, z\) ) in 3-dimensional space, you can write it in spherical coordinates by using the formulas:
    🔗
    • \(\displaystyle \rho^{2}=x^{2}+y^{2}+z^{2}\)
      🔗
      🔗
    • Use trigonometry to find \(\varphi\) and \(\theta\text{.}\)
      🔗
      🔗
    🔗
    Given a point ( \(\rho, \varphi, \theta\) ) in 3-dimensional space, you can write it in Cartesian coordinates by using the formulas:
    🔗
    • \(\displaystyle x=\rho \sin (\varphi) \cos (\theta)\)
      🔗
      🔗
    • \(\displaystyle y=\rho \sin (\varphi) \sin (\theta)\)
      🔗
      🔗
    • \(z=\rho \cos (\varphi)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Note 4.9.9.

    Note that in spherical coordinates you need to replace \(z\) as well.
    🔗
    You could geometrically (as we have done before) find the Jacobian of this change of variables. Instead, we will use the following formula.
    🔗
    🔗

    Remark 4.9.10. Writing a Triple Integral in Spherical Coordinates.

    To set up an iterated integral in cylindrical coordinates:
    🔗
    1. Use the order \(d\rho d \varphi d \theta\text{.}\)
      🔗
      🔗
    2. Start from the origin \((0,0,0)\) and radiate outwards
      🔗
      🔗
    3. The first function you encounter, preventing out from expanding outwards is the lower bound for \(\rho\text{,}\) the second is the upper bound.
      🔗
      🔗
    4. Start at the positive \(z\)-axis and open outwards like a hand-held fan
      🔗
      🔗
    5. The first function you encounter, preventing out from fanning outwards is the lower bound for \(\varphi\text{,}\) the second is the upper bound.
      🔗
      🔗
    6. For \(\theta\text{,}\) similar with the polar coordinates, the bounds stem from the largest counter-clockwise rotation a point can do within the region of integration.
      🔗
      🔗
    7. The iterated integral should have the form
      \begin{equation*} \int_{\alpha}^{\beta} \int_{a}^{b} \int_{\rho=g(\varphi, \theta)}^{\rho=h(\varphi, \theta)} f(\rho, \varphi, \theta) \rho^{2} \sin (\varphi) d \rho d \varphi d \theta \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Note 4.9.11. Evaluating a Triple Integral for Volume.

    As previously the integral that represents the volume of a region is calculated by the above integrals, by setting \(f(\rho, \varphi, \theta) = 1 = f(r , \theta , z)\text{.}\)
    🔗
    🔗

    Example 4.9.12.

    Set up (but do not evaluate) a triple integral, in spherical coordinates, of \(f(x,y,z)= x^2+y^2+z^2\) over the volume of the “ice cream cone” \(D\) bounded from above by the sphere \(\rho = 4 \cos\phi\text{,}\) \(\phi\leq \frac{\pi}{2}\) and from below by the cone \(\varphi=\frac{\pi}{6}\) (above the \(xy\)-plane).
    🔗
    Solution.
    Using \(\rho^{2}=x^{2}+y^{2}+z^{2}\) the function \(f(x,y,z) = x^2+y^2+z^2\) transforms to \(f(\rho, \varphi , \theta )= \rho^2 \text{.}\) The upper bound for \(\rho\) is given as \(\rho = 4\cos\varphi \gt 0\) while the lower bound is implied to be 0 since cones of the form \(\varphi = c \) pass through the origin (0,0,0), and when radiating away from the origin those cones do not obstruct.
    🔗
    Since the sphere and the cone encompass a portion of the positive \(z\)-axis the lower bound for \(\varphi\) is 0, while the upper bound is provided as \(\varphi = \frac{\pi}{6}\text{.}\) Lastly there are no restrictions for \(\theta\) hence the bounds for integration are 0 and \(2\pi\) receptively.
    🔗
    \begin{gather*} \int_0^{2\pi}\int_0^{\frac{\pi}{6}}\int_0^{4\cos\varphi} f(\rho, \varphi , \theta) \rho^2 \sin \varphi\ d\rho d\varphi d\theta = \int_0^{2\pi}\int_0^{\frac{\pi}{6}}\int_0^{4\cos\varphi} \rho^2 \rho^2 \sin \varphi\ d\rho d\varphi d\theta =\\ \int_0^{2\pi}\int_0^{\frac{\pi}{6}}\int_0^{4\cos\varphi} \rho^4 \sin \varphi\ d\rho d\varphi d\theta \end{gather*}
    🔗
    🔗
    🔗

    Example 4.9.13.

    A solid region \(D\) lies inside the paraboloid \(4-x^{2}-y^{2}-z=0\text{,}\) and above the plane \(z=3\text{,}\) as shown below. Express the triple integral \(\iiint_{D} 2z(x^2+y^2) d V\) in cylindrical coordinates, then evaluate it.
    🔗
    Solution.
    Using \(r^{2}=x^{2}+y^{2}\) the function \(f(x,y,z) = 2z(x^2+y^2)\) transforms to \(f(r, \theta , z )=2 zr^2 \text{.}\) The paraboloid \(z=4-x^2-y^2 = 4-(x^2+y^2)= 4-r^2\) and the plane \(z=3\) intersect when \(4-r^2 = 3 \Rightarrow r^2 = 1 \Rightarrow r=1\text{.}\) Since for \(r=0\) the \(z\) coordinate of the paraboloid is \(z=4-0=4 \gt 3\text{,}\) the upper bound for z is given by the paraboloid and the lower by the plane.
    🔗
    The finite region for \(r\) of the above intersection is given by \(0\leq r \leq 1\text{.}\) Lastly there are no restrictions for \(\theta\) hence the bounds for integration are 0 and \(2\pi\) receptively.
    🔗
    \begin{gather*} \int_0^{2\pi}\int_0^{1}\int_3^{4-r^2} (2zr^2)r\ dz dr d\theta = \int_0^{2\pi}\int_0^{1}\int_3^{4-r^2} 2zr^3 \ dz dr d\theta = \int_0^{2\pi}\int_0^{1} \left . r^3z^2 \right |_3^{4-r^2} dr d\theta =\\ \int_0^{2\pi}\int_0^{1} r^3(4-r^2)^2- 9r^2\ dr d\theta = \int_0^{2\pi}\int_0^{1} 16r^3-8r^5+r^7 - 9r ^3 \ dr d\theta =\\ \int_0^{2\pi}\left . 4r^4-\frac{4}{3}r^6+\frac{1}{8} r^8 - \frac{9}{4} r ^4 \right |_0^1 d\theta = \int_0^{2\pi} 4-\frac{4}{3}+\frac{1}{8} - \frac{9}{4} d\theta = \int_0^{2pi} \frac{13}{24} d\theta = \left . \frac{13}{24}\theta \right |_0^{2\pi} =\frac{13}{12}\pi\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Definition 4.9.14. Jacobian in Three Dimensions and Integrals.

    Let \(T: x=g(u, v, w), y=h(u, v, w)\text{,}\) and \(z=q(u, v, w)\) be a transformation that maps a closed and bounded region \(S\) in \(u v w\)-space to a region \(D\) in \(x y z\)-space. Assume \(T\) is one-to-one on the interior of \(S\) and that \(g, h\text{,}\) and \(q\) have continuous first partial derivatives there. If \(f\) is continuous on \(D\text{,}\) then
    \begin{equation*} \iiint_{D} f(x, y, z) d V=\iiint_{S} f(g(u, v, w), h(u, v, w), q(u, v, w))|J(u, v, w)| d V \end{equation*}
    where
    \begin{align*} J(u, v, w) \amp =\frac{\partial(x, y, z)}{\partial(u, v, w)}=\left|\begin{array}{lll} x_{u} \amp x_{v} \amp x_{w} \\ y_{u} \amp y_{v} \amp y_{w} \\ z_{u} \amp z_{v} \amp z_{w} \end{array}\right|\\ \amp =x_{u}\left(y_{v} z_{w}-y_{w} z_{v}\right)-x_{v}\left(y_{u} z_{w}-y_{w} z_{u}\right)+x_{w}\left(y_{u} z_{v}-y_{v} z_{u}\right)\\ \amp =z_{u}\left(x_{v} y_{w}-x_{w} y_{v}\right)-z_{v}\left(x_{u} y_{w}-x_{w} y_{u}\right)+z_{w}\left(x_{u} y_{v}-x_{v} y_{u}\right) \end{align*}
    is the Jacobian of the transformation \(T\) which measures how volume around a point ( \(x, y, z\) ) change as we move to \(u v w\)-space.
    🔗
    🔗

    Example 4.9.15.

    Let \(u=\rho, v=\varphi\text{,}\) and \(w=\theta\text{.}\) Then,
    🔗
    Solution 1.
    \begin{gather*} J(\rho, \varphi, \theta) =\left|\begin{array}{ccc} \sin (\varphi) \cos (\theta) \amp \rho \cos (\varphi) \cos (\theta) \amp -\rho \sin (\varphi) \sin (\theta) \\ \sin (\varphi) \sin (\theta) \amp \rho\cos (\varphi) \sin (\theta) \amp \rho \sin (\varphi) \cos (\theta) \\ \cos (\varphi) \amp -\rho \sin (\varphi) \amp 0 \end{array}\right| =\\ \sin\varphi\cos\theta \left | \begin{matrix} \rho\cos\varphi\sin\theta \amp \rho\sin\varphi\cos\theta \\ -\rho\sin\varphi \amp 0 \end{matrix} \right | - \rho\cos\varphi\cos\theta \left | \begin{matrix} \sin\varphi\sin\theta \amp \rho\sin\varphi\cos\theta\\ \cos\varphi \amp 0 \end{matrix} \right |\\ +(-\rho\sin\varphi\sin\theta) \left | \begin{matrix} \sin\varphi\sin\theta \amp \rho\cos\varphi\sin\theta \\ \cos\varphi \amp -\rho\sin\varphi \end{matrix} \right | =\\ \rho^2\sin^3\varphi\cos^2\theta +\rho^2\cos^2\varphi\sin^2\theta\sin\varphi +(-\rho\sin\varphi\sin\theta)\left ( -\rho\sin^2\varphi\sin\theta -\rho\cos^2\varphi\sin\theta \right) =\\ \rho^2\sin^3\varphi\cos^2\theta +\rho^2\cos^2\varphi\sin^2\theta\sin\varphi +\rho^2\sin^3\varphi\sin^2\theta+ \rho^2\cos^2\varphi\sin\varphi\cos^2\theta =\\ \rho^2\sin^3\varphi (\cos^2\theta +\sin^2\theta)+\rho^2\sin\varphi\cos^2\\ varphi (\sin^2 \theta + \cos^2\theta)=\\ \rho^2\sin\varphi (\sin^2\varphi +\cos^2\varphi)= \rho^2\sin\varphi \end{gather*}
    🔗
    🔗
    Solution 2.
    Since \(0 \leq \varphi \leq \pi, \sin (\varphi) \geq 0\text{.}\) It follows that
    \begin{equation*} \mid J\left(\rho, \varphi, \theta\left)|=\left|\rho^{2} \sin (\varphi)\right|=\rho^{2} \sin (\varphi) \right.\right.\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Example 4.9.16.

    Set up (but do not evaluate) a triple integral that gives the volume of the “ice cream cone” \(D\) below the sphere \(x^2+y^2+z^2=4\text{,}\) and above the cone \(z=\sqrt 3 \sqrt{x^2+y^2}\text{.}\)
    🔗
    Solution.
    Using \(\rho^{2}=x^{2}+y^{2}+z^{2}\) the sphere \(x^2+y^2+z^2=4\) transforms to \(\rho^2 =4 \Rightarrow \rho =2\) (Restricting the values of \(r\) to be non-negative). Using \(z=\rho \cos\varphi\text{,}\) \(x=\rho\sin\varphi\cos\theta\) and \(y=\rho\sin\varphi\sin\theta\) the cone transforms to \(\rho \cos\varphi = \sqrt 3 \sqrt{ \rho^2\sin^2\varphi\cos^2\theta + \rho^2\sin^2\varphi\sin^2\theta } = \sqrt 3\sqrt{ \rho^2\sin^2\varphi(\cos^2\theta + \sin^2\theta ) } = \sqrt 3\sqrt{ \rho^2\sin^2\varphi } =\sqrt 3\rho\sin\varphi \) since \(\sin\varphi \geq 0 \) for \(0\leq \varphi \leq \pi\text{.}\) This implies that for \(\rho\not = 0\text{,}\) \(\tan \varphi = \frac{\sqrt 3}{3}\Rightarrow \varphi= \frac{\pi}{6}\) (The value \(\varphi = \frac{7\pi}{6}\) is disregarded since we need \(0\leq \varphi \leq \pi\)).
    🔗
    The upper bound for \(\rho\) is given as \(\rho = 4\) while the lower bound is implied to be 0 since cones of the form \(\varphi = c \) pass through the origin (0,0,0), and when radiating away from the origin those cones do not obstruct.
    🔗
    Since the sphere and the cone encompass a portion of the positive \(z\)-axis (between \(z=0\) and \(z=2\)) the lower bound for \(\varphi\) is 0, while the upper bound is provided as \(\varphi = \frac{\pi}{6}\text{.}\) Lastly there are no restrictions for \(\theta\) hence the bounds for integration are 0 and \(2\pi\) receptively.
    🔗
    \begin{equation*} \int_0^{2\pi}\int_0^{\frac{\pi}{6}}\int_0^{2} \rho^2 \sin \varphi\ d\rho d\varphi d\theta \end{equation*}
    🔗
    🔗
    🔗

    Example 4.9.17.

    Set up (but do not evaluate) a triple integral in spherical coordinates that gives the volume inside the ball \(\rho \leq 1\) and above the plane \(z=1/2\) (pictured below).
    🔗
    Solution.
    Using \(\rho^{2}=x^{2}+y^{2}+z^{2}\) the sphere \(x^2+y^2+z^2\leq 1\) transforms to \(\rho\leq 1 \) (Restricting the values of \(r\) to be non-negative). Using \(z=\rho \cos\varphi\text{,}\) the plane transforms to \(\rho \cos\varphi = \frac{1}{2}\text{.}\) To find the intersection of the two surfaces:
    \begin{equation*} \left . \begin{matrix} \rho \cos \varphi \amp = \amp \frac{1}{2} \\ \rho \amp = \amp 1 \end{matrix} \right \} \Rightarrow \cos\varphi = \frac{1}{2} \Rightarrow \varphi = \frac{\pi}{3}\text{.} \end{equation*}
    🔗
    Since the sphere and the cone encompass a portion of the positive \(z\)-axis (between \(z=1/2\) and \(z=1\))the lower bound for \(\varphi\) is 0, while the upper bound is provided as \(\varphi = \frac{\pi}{3}\text{.}\) As far as \(\rho\) is concerned the upper bound is 1, the lower bound is implied by the equation \(\rho\cos\varphi = \frac{1}{2}\) to be \(\rho = \frac{1}{2}\sec \varphi\text{.}\) Lastly there are no restrictions for \(\theta\) hence the bounds for integration are 0 and \(2\pi\) receptively.
    🔗
    \begin{equation*} \int_0^{2\pi}\int_0^{\frac{\pi}{3}}\int_{\frac{1}{2}\sec\varphi}^{1} \rho^2 \sin \varphi\ d\rho d\varphi d\theta \end{equation*}
    🔗
    🔗
    🔗

    Example 4.9.18.

    Find the volume of the sphere \(x^{2}+y^{2}+z^{2}=a^{2}, a \gt 0\text{.}\)
    🔗
    Solution.
    Using \(\rho^{2}=x^{2}+y^{2}+z^{2}\) the sphere \(x^2+y^2+z^2=a^2\) transforms to \(\rho^2 =a^2 \Rightarrow \rho =a\) (Restricting the values of \(r\) to be non-negative). There are no restriction on \(\varphi\) and \(\theta\text{,}\) hence their respective range is implied to be \(0\leq \varphi \pi\) and \(0\leq \theta\leq 2\pi\text{.}\)
    🔗
    \begin{gather*} \int_0^{2\pi}\int_0^{\pi}\int_{0}^{a} \rho^2 \sin \varphi \ d\rho d\varphi d\theta = \int_0^{2\pi}\int_0^{\pi}\left. \frac{\rho^3}{3} \sin \varphi \right |_{0}^{a} d\varphi d\theta= \int_0^{2\pi}\int_0^{\pi} \frac{a^3}{3} \sin \varphi\ d\varphi d\theta =\\ \int_0^{2\pi}\left . -\frac{a^3}{3} \cos \varphi \right |_0^{\pi} d\theta = \int_0^{2\pi} -\frac{a^3}{3} \cos \pi +\frac{a^3}{3} \cos 0\ d\theta = \int_0^{2\pi} \frac{2a^3}{3} d\theta = \left . \frac{2a^3}{3} \theta \right |_0^{2\pi} = \frac{4\pi a^3}{3} \end{gather*}
    🔗
    🔗
    🔗

    Example 4.9.19.

    Set up (but do not evaluate) a triple integral in spherical coordinates that gives the volume inside the ball \(\rho \leq 2\) and but outside the cylinder \(x^2+y^2=1\) (from OpenStax).
    🔗
    Solution.
    Using \(x=\rho\sin\varphi\cos\theta\) and \(y=\rho\sin\varphi\sin\theta\text{,}\) the cylinder \(x^2+y^2=1\) transforms to \(\rho^2 \sin^2\varphi\cos^2\theta + \rho^2 \sin^2\varphi\sin^2\theta = 1 \Rightarrow \rho^2 \sin^2\varphi (\cos^2\theta +\sin^2\theta )=1 \Rightarrow \rho^2 \sin^2\varphi = 1 \Rightarrow\) \(\rho \sin\varphi = 1\text{,}\) since we restrict \(\rho\) to have non-negative values and \(\varphi\) to be between \(0\) and \(\pi\text{.}\) To find the intersection of the two surfaces:
    \begin{equation*} \left . \begin{matrix} \rho \sin\varphi \amp = \amp 1 \\ \rho \amp = \amp 2 \end{matrix} \right \} \Rightarrow \sin\varphi = \frac{1}{2} \Rightarrow \varphi = \frac{\pi}{6} \text{ or } \frac{5\pi}{6}\text{.} \end{equation*}
    To investigate whether or not one needs to take into account the values of \(\varphi\) from \(0\) to \(\frac{\pi}{6}\text{,}\) and from \(\frac{5\pi}{6}\) to \(\pi\text{,}\) notice that the \(z\)-axis (\(\varphi = 0\) or \(\varphi = \pi\)) lie inside NOT outside the cylinder since any point of the form \(P(0,0,a)\) has \(x_P^2+y_P^2 = 0+0 = 0 \lt 1\) . Hence, the bounds for \(\varphi\) are \(\frac{\pi}{6}\) and \(\frac{5\pi}{6}\text{.}\) As far as \(\rho\) is concerned the upper bound is 2, the lower bound is implied by the equation \(\rho\sin\varphi = 1\) to be \(\csc \varphi\text{.}\) Lastly there are no restrictions for \(\theta\) hence the bounds for integration are 0 and \(2\pi\) receptively.
    \begin{equation*} \int_0^{2\pi}\int_{\frac{\pi}{6}}^{\frac{5\pi}{6}}\int_{\csc\varphi}^{2} \rho^2 \sin \varphi\ d\rho d\varphi d\theta \end{equation*}
    🔗
    🔗

    Example 4.9.20.

    Set up (but do not evaluate) a triple integral using cylindrical coordinates that gives the 4D net volume bounded by a function \(f(r, \theta, z)\) and \(x y z\)-space, on a region \(D\) bounded below by the plane \(z=0\text{,}\) laterally by the circular cylinder \((x-1)^{2}+y^{2}=1\text{,}\) and above by the paraboloid \(z=4-x^{2}-y^{2}\text{.}\)
    🔗
    Solution.
    Using \(r^{2}=x^{2}+y^{2}\) the paraboloid \(z= 4-(x^2+y^2)\) transforms to \(z=4-r^2 \text{.}\) For the cylinder \((x-1)^{2}+y^{2}=1\text{,}\) notice that it lies above the first and forth quadrants. hence \(\theta\) much be on a sub-interval of \((-\frac{\pi}{2},\frac{\pi}{2})\text{.}\) Utilizing \(x=r\cos\theta\) and \(y=r\sin\theta\text{,}\) one has
    \begin{gather*} (x-1)^2+y^2= 1 \Rightarrow (r\cos\theta - )^2+r^2\sin^2\theta = 1 \Rightarrow r^2\cos^2\theta -2r\cos\theta +1 +r^2\sin^2\theta = 1 \Rightarrow\\ r^2(\cos^2\theta +\sin^2\theta )-2r\cos\theta = 0 \Rightarrow r^2-2r\cos\theta = 0 \Rightarrow r(r-2\cos\theta) = 0\Rightarrow r= 0 \text{ or } r= 2\cos\theta \end{gather*}
    For the range of \(\theta\) mentioned above, \(r=2\cos\theta \geq 0\) and hence one has the lower and upper bound for \(r\) as \(0\) and \(2\cos\theta\) respectively. Lastly, to verify that the \(\theta\) ranges over \((-\frac{\pi}{2},\frac{\pi}{2})\) and not a subinterval, observe that the second coordinate of the points of this circle \(y_c\) satisfies \(y_c = r \sin\theta = 2\cos\theta\sin\theta\text{.}\) In this expression for \(\theta = -\frac{\pi}{2}\) the coordinate is 0, in between \(-\frac{\pi}{2}\) and \(0\) is negative, between \(0\) and \(\frac{\pi}{2}\) is positive and at \(\theta = \frac{\pi}{2}\) the coordinate is 0 again. Hence we traverse the circle exactly once over this interval of \(\theta\text{.}\)
