    Section 2.2 Scalar-Valued Functions

    In the section for vector-valued functions, we looked at functions with one input variable and multiple output variables (called curves).
    🔗
    In this section, we will look at functions of the form \(f(x, y)=z\text{,}\) having two input variables and one output variable (called surfaces).
    🔗
    The outputs of vector-valued functions were vectors. The outputs of scalar-valued functions are scalars (numbers).
    🔗

    Definition 2.2.1. Scalar-Valued Functions.

    A scalar-valued function of the form \(z=f(x, y)\) is a function whose domain (set of inputs) is a subset of the \(x y\)-plane ( \(\mathbb{R}^{2}\) ) and whose range (set of outputs) is a subset of the real line ( \(\mathbb{R}\) ).
    🔗
    The graph of \(f\) is called a surface and consists of all points ( \(x, y, f(x, y)\) ) where \((x, y)\) is in the domain of \(f\text{.}\)
    🔗
    🔗

    Example 2.2.2.

    Consider the graph of \(f(x, y)=y^{2}-x^{2}\) shown below. Determine whether the points \(\left(\frac{1}{2}, \frac{1}{4},-\frac{3}{16}\right)\) and \(\left(-1, \frac{1}{3}, 2\right)\) lie on the graph of \(f\text{.}\)
    🔗
    Solution.
    A point \((x_0, y_0, z_0)\) lies on the graph of \(f\) exactly when \(z_0 = f(x_0, y_0)\text{.}\) For the first point:
    \begin{equation*} f\left( \frac{1}{2}, \frac{1}{4} \right) = \left( \frac{1}{4} \right)^2 - \left( \frac{1}{2} \right)^2 = \frac{1}{16}-\frac{4}{16} = -\frac{3}{16} \end{equation*}
    which matches the third coordinate, so \(\left(\frac{1}{2}, \frac{1}{4},-\frac{3}{16}\right)\) lies on the graph of \(f\text{.}\) For the second point:
    \begin{equation*} f\left( -1, \frac{1}{3} \right) = \left( \frac{1}{3} \right)^2 - (-1)^2 = \frac{1}{9}-1 = -\frac{8}{9} \neq 2 \end{equation*}
    so \(\left(-1, \frac{1}{3}, 2\right)\) does not lie on the graph of \(f\text{.}\)
    🔗
    🔗
    🔗

    Note 2.2.3.

    Given a function \(z=f(x, y)\) :
    🔗
    • To find its domain, denoted \(\operatorname{dom}(f)\text{,}\) determine all \((x, y)\) that can be plugged into \(f\text{.}\)
      🔗
      🔗
    • To find its range, denoted \(\operatorname{rang}(f)\text{,}\) determine all values of \(z\) that have a pair \((x, y)\) mapped to it.
      🔗
      🔗
    🔗
    🔗

    Example 2.2.4.

    Find the domain and range of the following functions:
    🔗
    1. Plane, \(f(x, y)= 4x+ y+1\)
      🔗
      🔗
    2. Paraboloid, \(f(x, y)=x^{2}+y^{2}\)
      🔗
      🔗
    3. Upper Half of a Sphere with Radius 1, \(f(x, y)=\sqrt{1-x^2 -y^{2}}\)
      🔗
      🔗
    🔗
    Solution 1.
    Any pair \((x,y)\) can be plugged into \(4x+y+1\text{,}\) so \(\operatorname{dom}(f) = \mathbb{R}^2\text{,}\) the entire \(xy\)-plane. For the range, fixing \(y=0\) the outputs \(f(x,0) = 4x+1\) already take every real value as \(x\) varies, so \(\operatorname{rang}(f) = \mathbb{R}\text{.}\)
    🔗
    🔗
    Solution 2.
    Again any pair can be plugged in, so \(\operatorname{dom}(f) = \mathbb{R}^2\text{.}\) Since \(x^2+y^2 \geq 0\text{,}\) no negative output is possible. The output 0 is attained at \((0,0)\text{,}\) and every \(z \gt 0\) is also attained, for instance at \((\sqrt{z}, 0)\text{.}\) Hence \(\operatorname{rang}(f) = [0, \infty)\text{.}\)
    🔗
    🔗
    Solution 3.
    Here we need the expression under the square root to be non-negative:
    \begin{equation*} 1-x^2-y^2 \geq 0 \Leftrightarrow x^2+y^2 \leq 1 \end{equation*}
    so \(\operatorname{dom}(f)\) is the disk of radius 1 centered at the origin (including its boundary circle). The square root is non-negative, and the outputs run from \(f=0\) (attained on the boundary circle \(x^2+y^2=1\)) up to \(f=1\) (attained at \((0,0)\)), so \(\operatorname{rang}(f) = [0,1]\text{.}\)

    Definition 2.2.5. Planes in \(x y z\)-space.

    A plane in \(x y z\)-space is the set of all points that satisfy the equation
    \begin{equation*} a x+b y+c z=d\text{,} \end{equation*}
    where \(a, b, c\text{,}\) and \(d\) are real numbers.
    🔗
    🔗

    Remark 2.2.6.

    In order to find an equation for a plane, all we need is:
    🔗
    • A point in the plane.
      🔗
      🔗
    • The orientation (tilt) of the plane.
      🔗
      🔗
    🔗
    The orientation is given by a vector orthogonal to every other vector in the plane. We call this vector a normal vector to the plane.
    🔗
    Given a point \(P_{0}\left(x_{0}, y_{0}, z_{0}\right)\) on a plane \(\pi\) and a vector \(\vec{n}=\langle a, b, c\rangle\) normal to \(\pi\text{,}\) the equation for \(\pi\) is given by
    \begin{equation*} a\left(x-x_{0}\right)+b\left(y-y_{0}\right)+c\left(z-z_{0}\right)=0\text{.} \end{equation*}
    🔗
    🔗

    Note 2.2.7.

    To find a vector normal to a plane \(\pi\text{,}\) all you need is the cross-product of two non-parallel vectors in the plane (since they define the plane uniquely).
    🔗
    🔗

    Example 2.2.8.

    Find an equation for the plane that passes through the points \(P(-1,-1,-1), Q(-1,-1,1)\text{,}\) and \(R(1,1,1)\text{.}\)
    🔗
    Solution.
    To find an equation for the plane we need a point in the plane (we have three) and a normal vector, which we get as the cross product of two non-parallel vectors in the plane. Two vectors in the plane are
    \begin{gather*} \vec{PQ} = \langle -1-(-1), -1-(-1), 1-(-1) \rangle = \langle 0,0,2 \rangle\\ \vec{PR} = \langle 1-(-1), 1-(-1), 1-(-1) \rangle = \langle 2,2,2 \rangle \end{gather*}
    and they are not parallel (no scalar multiple of \(\langle 0,0,2 \rangle\) can have a nonzero first component). Their cross product is normal to the plane:
    \begin{gather*} \vec{n} = \vec{PQ} \times \vec{PR} = \left| \begin{matrix} \vec{i} \amp \vec{j} \amp \vec{k} \\ 0 \amp 0 \amp 2 \\ 2 \amp 2 \amp 2 \end{matrix}\right|\\ = \left| \begin{matrix} 0 \amp 2 \\ 2 \amp 2 \end{matrix}\right|\vec{i} - \left| \begin{matrix} 0 \amp 2 \\ 2 \amp 2 \end{matrix}\right|\vec{j} + \left| \begin{matrix} 0 \amp 0 \\ 2 \amp 2 \end{matrix}\right|\vec{k}\\ = \left( 0(2)-2(2) \right)\vec{i} - \left( 0(2)-2(2) \right)\vec{j} + \left( 0(2)-0(2) \right)\vec{k} = \langle -4,4,0 \rangle \end{gather*}
    Using the point \(P(-1,-1,-1)\) and the normal vector \(\vec{n} = \langle -4,4,0 \rangle\text{:}\)
    \begin{equation*} -4\left( x-(-1) \right)+4\left( y-(-1) \right)+0\left( z-(-1) \right) = 0 \Rightarrow -4x+4y = 0 \Rightarrow y = x \end{equation*}
    As a check, all three points \(P\text{,}\) \(Q\text{,}\) and \(R\) satisfy the equation \(y=x\text{.}\)
    🔗
    🔗
    🔗

    Remark 2.2.9. Normal Vector to a Plane.

    Given the plane \(a x+b y+c z=d\text{,}\) the vector \(\vec{n}=\langle a, b, c\rangle\) is a normal vector to the plane.
    🔗
    🔗

    Note 2.2.10.

    • Whether two planes are parallel, orthogonal, or neither, can be answered by asking the same question about their normal vectors.
      🔗
      🔗
    • If two planes are not parallel, they always intersect in a line. The direction of this line is given by the cross product of the normal vectors to the planes.
      🔗
      🔗
    🔗
    🔗

    Example 2.2.11.

    Determine whether the planes \(\pi_{1}\) given by \(3 x+2 y+ z=30\) and \(\pi_{2}\) given by \(-3 x+4 y+6 z=0\) are parallel, orthogonal or neither.
    🔗
    Solution.
    The normal vectors are \(\vec{n}_1 = \langle 3,2,1 \rangle\) and \(\vec{n}_2 = \langle -3,4,6 \rangle\text{,}\) and we answer the question by asking it about them. If they were parallel there would be a scalar \(c\) with \(c\vec{n}_1 = \vec{n}_2\text{;}\) the first components force \(c=-1\) while the second components force \(c=2\text{,}\) so the normal vectors (and hence the planes) are not parallel. Checking orthogonality with the dot product:
    \begin{equation*} \vec{n}_1 \cdot \vec{n}_2 = 3(-3)+2(4)+1(6) = -9+8+6 = 5 \neq 0 \end{equation*}
    so the normal vectors are not orthogonal either. Hence the planes are neither parallel nor orthogonal.
    🔗
    🔗
    🔗

    Example 2.2.12.

    Find an equation of the line where the planes \(\pi_{1}\) and \(\pi_{2}\) intersect where
    \begin{equation*} \pi_{1}:3x+2 y+ z=1 ; \quad \pi_{2}: x+y+z=1 \end{equation*}
    🔗
    Solution.
    The normal vectors are \(\vec{n}_1 = \langle 3,2,1 \rangle\) and \(\vec{n}_2 = \langle 1,1,1 \rangle\text{,}\) which are not scalar multiples of each other, so the planes are not parallel and they intersect in a line. The direction of this line is given by the cross product of the normal vectors:
    \begin{gather*} \vec{v} = \vec{n}_1 \times \vec{n}_2 = \left| \begin{matrix} \vec{i} \amp \vec{j} \amp \vec{k} \\ 3 \amp 2 \amp 1 \\ 1 \amp 1 \amp 1 \end{matrix}\right|\\ = \left| \begin{matrix} 2 \amp 1 \\ 1 \amp 1 \end{matrix}\right|\vec{i} - \left| \begin{matrix} 3 \amp 1 \\ 1 \amp 1 \end{matrix}\right|\vec{j} + \left| \begin{matrix} 3 \amp 2 \\ 1 \amp 1 \end{matrix}\right|\vec{k}\\ = \left( 2(1)-1(1) \right)\vec{i} - \left( 3(1)-1(1) \right)\vec{j} + \left( 3(1)-2(1) \right)\vec{k} = \langle 1,-2,1 \rangle \end{gather*}
    We also need a point on the line, that is, a point satisfying both plane equations. Subtracting the equation of \(\pi_2\) from the equation of \(\pi_1\) eliminates \(z\text{:}\)
    \begin{equation*} (3x+2y+z)-(x+y+z) = 1-1 \Rightarrow 2x+y = 0 \end{equation*}
    Choosing \(x=0\) gives \(y=0\text{,}\) and then the equation of \(\pi_2\) gives \(z=1\text{,}\) so the point \((0,0,1)\) lies on both planes. Hence the line of intersection is
    \begin{equation*} \vec{r}(t) = \langle 0,0,1 \rangle + t\langle 1,-2,1 \rangle = \langle t, -2t, 1+t \rangle, \quad -\infty \lt t \lt \infty \end{equation*}
    As a check, substituting the parametric equations into both plane equations: \(3t-4t+(1+t) = 1\) and \(t-2t+(1+t) = 1\) for every \(t\text{.}\)

    Example 2.2.13.

    Describe the level curve you get when intersecting the cone \(z=\) \(\sqrt{2x^{2}+2y^{2}}\) with the plane \(z=1\text{.}\)
    🔗
    Solution.
    The level curve is defined by the equation \(1 = \sqrt{2x^2+2y^2}\text{.}\) Squaring both sides:
    \begin{equation*} 1 = 2x^2+2y^2 \Rightarrow x^2+y^2 = \frac{1}{2} \end{equation*}
    This is a circle centered at the origin of radius \(\sqrt{\frac{1}{2}} = \frac{\sqrt{2}}{2}\text{,}\) drawn at height \(z=1\) on the cone, as in the picture above.

    🔗

    Definition 2.2.14. Traces of Surfaces.

    When you intersect a surface \(z=f(x, y)\) with planes of the form \(x=x_{0}\text{,}\) \(y=y_{0}\text{,}\) and \(z=z_{0}\text{,}\) the corresponding level curve is called a trace of the surface. Vertical trace refers to the intersection with a plane of the form \(x=x_0\) or \(y=y_0\)
    🔗
    🔗

    Example 2.2.15.

    Describe the vertical trace you get when intersecting the hyperbolic paraboloid \(z=y^{2}-x^{2}\) with the plane \(y=1\text{.}\)
    🔗
    Solution.
    Substituting \(y=1\) into the equation of the surface:
    \begin{equation*} z = 1^2-x^2 = 1-x^2 \end{equation*}
    The vertical trace is a downward-opening parabola lying in the plane \(y=1\text{,}\) with vertex at the point \((0,1,1)\) and passing through the points \((\pm 1, 1, 0)\text{,}\) as the picture above shows.

    Remark 2.2.17.

    Suppose you have a function of the form \(w=F(x, y, z)\text{,}\) which corresponds to an object in 4 dimensions.
    🔗
    We can intersect this function with a hyperplane of the form \(w=c\) to get a 3D-surface called a level surface defined by the equation \(c=F(x, y, z)\text{.}\)
    🔗
    🔗

    Example 2.2.18.

    Consider the function \(w=x^{2}+2y^{2}+3z^{2}\text{.}\) Describe the level surface you get when intersecting \(w\) with the hyperplane \(w=4\text{.}\)
    🔗
    Solution.
    The level surface is defined by the equation
    \begin{equation*} x^2+2y^2+3z^2 = 4 \Rightarrow \frac{x^2}{4}+\frac{y^2}{2}+\frac{z^2}{4/3} = 1 \end{equation*}
    This is an ellipsoid centered at the origin, crossing the \(x\)-axis (\(y=z=0\)) at \(x=\pm 2\text{,}\) the \(y\)-axis (\(x=z=0\)) at \(y=\pm\sqrt{2}\text{,}\) and the \(z\)-axis (\(x=y=0\)) at \(z=\pm\frac{2}{\sqrt{3}}\text{,}\) as shown below.
    🔗
    🔗

    Note 2.2.19. Implicit vs. Explicit Surfaces.

    Consider the plane \(\pi\) defined by \(x+2 y-z=4\text{.}\) Since \(z\) isn’t by itself on one side of the equation, we say that \(z\) is given implicitly as a function of \(x\) and \(y\text{.}\)
    🔗
    If you solve for \(z\) and write \(\pi\) as \(z=x+2 y-4\text{,}\) then we say \(z\) is given explicitly as a function of \(x\) and \(y\text{.}\)
    🔗
    The same definition of implicit or explicit applies for functions in higher dimensions.
    🔗
    🔗

    Example 2.2.20.

    For each of the following equations, determine whether \(z\) is given implicitly or explicitly as a function of \(x\) and \(y\text{.}\) If \(z\) is given implicitly, write it explicitly (if it isn’t possible, explain why).
    🔗
    1. \(z=\sin(x+y+3)\text{.}\)
      🔗
      🔗
    2. \(4z+e^{\sin x-\cos y}= z+\cos x\text{.}\)
      🔗
      🔗
    3. \(z^{4}+3y^{2}=\log x\text{.}\)
      🔗
      🔗
    🔗
    Solution 1.
    Since \(z\) is by itself on one side of the equation, \(z\) is given explicitly as a function of \(x\) and \(y\text{.}\)
    🔗
    🔗
    Solution 2.
    Here \(z\) appears on both sides of the equation and is not by itself, so \(z\) is given implicitly. Solving for \(z\text{:}\)
    \begin{equation*} 4z-z = \cos x - e^{\sin x-\cos y} \Rightarrow 3z = \cos x - e^{\sin x-\cos y} \Rightarrow z = \frac{\cos x - e^{\sin x-\cos y}}{3} \end{equation*}
    so \(z\) can be written explicitly.
    🔗
    🔗
    Solution 3.
    Again \(z\) is given implicitly. Attempting to solve for \(z\text{:}\)
    \begin{equation*} z^4 = \log x - 3y^2 \Rightarrow z = \pm\sqrt[4]{\log x - 3y^2} \end{equation*}
    It is not possible to write \(z\) explicitly as a function of \(x\) and \(y\text{:}\) because of the \(\pm\text{,}\) every input \((x,y)\) with \(\log x - 3y^2 \gt 0\) corresponds to two different values of \(z\text{,}\) so \(z\) is not uniquely determined by \((x,y)\) and is therefore not a function of \(x\) and \(y\text{.}\)
