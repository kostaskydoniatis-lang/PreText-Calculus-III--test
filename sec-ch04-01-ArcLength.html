    Section 4.1 Arc Length

    Note 4.1.1.

    Given a curve \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle, a \leq t \leq b\text{,}\) we will derive a formula for calculating the length of \(\vec{r}(t)\text{.}\) First, we will talk about integrability.
    🔗
    🔗

    Definition 4.1.2. Integrability of Curves.

    Given a curve \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle, a \leq t \leq b\text{,}\) then
    \begin{equation*} \int_{a}^{b} \vec{r}(t) d t=\left\langle\int_{a}^{b} f(t) d t, \int_{a}^{b} g(t) d t, \int_{a}^{b} h(t) d t\right\rangle \end{equation*}
    🔗
    Hence, \(\vec{r}(t)\) is integrable on \([a, b]\) if and only if each of its components is integrable (continuous) on \([a, b]\text{.}\)
    🔗
    🔗

    Example 4.1.3.

    Compute \(\int_{0}^{1}\left\langle 3 t^{2}-2t, e^t+\cos(2\pi t)\right\rangle \, dt\text{.}\)
    🔗
    Solution.
    By the definition of integrability of curves, we integrate component-wise. For the first component:
    \begin{equation*} \int_0^1 3t^2 - 2t\, dt = \left. t^3 - t^2 \right|_0^1 = (1 - 1) - (0 - 0) = 0 \end{equation*}
    For the second component:
    \begin{equation*} \int_0^1 e^t + \cos(2\pi t)\, dt = \left. e^t + \frac{\sin(2\pi t)}{2\pi} \right|_0^1 = \left( e + \frac{\sin(2\pi)}{2\pi} \right) - \left( e^0 + \frac{\sin(0)}{2\pi} \right) = e - 1 \end{equation*}
    Hence
    \begin{equation*} \int_{0}^{1}\left\langle 3 t^{2}-2t, e^t+\cos(2\pi t)\right\rangle \, dt = \langle 0, e-1 \rangle \end{equation*}
    🔗
    🔗
    🔗

    Remark 4.1.4.

    Given \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle, \int_{a}^{b} \vec{r}(t) d t\) is NOT computing the net area bounded by the curve and the \(x y\)-plane (there is a way to do this which we will talk about later).
    🔗
    What \(\int_{a}^{b} \vec{r}(t) d t\) computes is a displacement vector.
    🔗
    🔗

    Definition 4.1.5. Displacement Vector.

    Given an integrable curve \(\vec{r}^{\prime}(t), a \leq t \leq b\text{,}\) then
    \begin{equation*} \int_{a}^{b} \vec{r}^{\prime}(t) d t=\vec{r}(b)-\vec{r}(a) \end{equation*}
    gives a displacement vector with starting point at the endpoint of \(\vec{r}(a)\) and ending point at the endpoint of \(\vec{r}(b)\text{.}\)
    🔗
    Moreover, \(\left|\int_{a}^{b} \vec{r}^{\prime}(t) d t\right|\) gives the displacement from the endpoint of \(\vec{r}(a)\) to the endpoint of \(\vec{r}(b)\text{.}\)
    🔗
    🔗

    Remark 4.1.6.

    When we say the displacement from the endpoint of \(\vec{r}(a)\) to the endpoint of \(\vec{r}(b)\text{,}\) in the above image, the distance between points B and C (NOT the distance along \(\vec{r}(t)\) ).
    🔗
    🔗

    Example 4.1.7.

    Below is the graph of \(\vec r\left(t\right)=\langle t ,\ln\left(\cos\left(t-\frac{\pi}{2}\right)\right)+1 \rangle, 0 \lt t \lt \pi\text{.}\) You can see the displacement vector from the endpoint of \(\vec{r}\left(\frac{\pi}{2}\right)\) to the endpoint of \(\vec{r}\left(\frac{\pi}{2}+\arccos (1/e)\right)\text{.}\)
    🔗
    Compare this to travelling from the endpoint \(\vec{r}\left(\frac{\pi}{2}\right)\) to the endpoint of \(\vec{r}\left(\frac{\pi}{2}+\arccos (1/e)\right)\) along \(\vec{r}(t)\) colored in light blue.
    🔗
    🔗

    Example 4.1.8.

    Suppose that a curve \(\vec{r}(t)\) satisfies \(\vec{r}^{\prime}(t)=\langle 2 t, 1\rangle\text{.}\) Find the displacement of a particle moving along \(\vec{r}(t)\) from \(t=1\) to \(t=3\text{.}\)
    🔗
    Solution.
    By the definition of the displacement vector, we integrate \(\vec{r}'(t)\) component-wise:
    \begin{equation*} \int_1^3 \vec{r}'(t)\, dt = \int_1^3 \langle 2t, 1 \rangle\, dt = \left\langle \left. t^2 \right|_1^3, \left. t \right|_1^3 \right\rangle = \langle 9-1, 3-1 \rangle = \langle 8, 2 \rangle \end{equation*}
    The displacement of the particle is the magnitude of this displacement vector:
    \begin{equation*} \left| \int_1^3 \vec{r}'(t)\, dt \right| = |\langle 8, 2 \rangle| = \sqrt{8^2 + 2^2} = \sqrt{68} = 2\sqrt{17} \end{equation*}
    🔗
    🔗
    🔗

    Note 4.1.9.

    Recall that integrals show up when we are summing up infinitely many things that are becoming infinitely small.
    🔗
    🔗
    For example, given an integrable function \(p(x), \int_{a}^{b} p(x) d x\) calculates the net area bounded by \(p(x)\) and the \(x\)-axis on \([a, b]\) by adding areas of rectangles that are becoming infinitely small.
    🔗

    🔗
    To find the length of a curve \(\vec{r}(t)\) (its \(\operatorname{arc}\) length) on the interval \([a, b]\text{,}\) we use a similar idea:
    🔗
    Partition the curve into line segments, and add the length of each line segment to approximate the length of \(\vec{r}(t)\text{.}\)
    🔗
    The graphs above show only the plots; you can drag and zoom them. To see the expressions behind them, or to save a copy and create your own version of the graphs, open them in a new page from here: link to the top left graph, link to the top right graph, link to the bottom graph
    🔗
    As with area, as the number of line segments approaches infinity (their lengths become infinitely small), we will get a better approximation of the arc length.
    🔗

    Definition 4.1.10. Length of a Curve (Arc length).

    Consider a curve \(\vec{r}(t)=\langle f(t), g(t), h(t)\rangle, a \leq t \leq b\text{,}\) where \(f^{\prime}, g^{\prime}\text{,}\) and \(h^{\prime}\) are continuous on \([a, b]\) and the curve is traversed only once on \([a, b]\text{.}\) Then the arclength of the curve between ( \(f(a), g(a), h(a)\) ) and ( \(f(b), g(b), h(b)\) ) is
    \begin{equation*} L=\int_{a}^{b} \sqrt{f^{\prime}(t)^{2}+g^{\prime}(t)^{2}+h^{\prime}(t)^{2}} d t=\int_{a}^{b}\left|\vec{r}^{\prime}(t)\right| d t \end{equation*}
    🔗
    🔗

    Example 4.1.11.

    A glider is soaring upward along the helix \(r(t)=\langle 0.98\cos (t), 0.98\sin (t) , \sqrt{1-0.98^2}t\rangle\text{.}\) How long is the glider’s path from \(t=0\) to \(t=2 \pi\) ?
    🔗
    Solution.
    The length of the glider’s path is the arc length of \(\vec{r}(t)\) from \(t=0\) to \(t=2\pi\text{.}\) First we compute the derivative and its magnitude:
    \begin{gather*} \vec{r}'(t) = \left\langle -0.98\sin (t),\ 0.98\cos (t),\ \sqrt{1-0.98^2} \right\rangle\\ |\vec{r}'(t)| = \sqrt{0.98^2\sin^2 (t) + 0.98^2\cos^2 (t) + \left( \sqrt{1-0.98^2} \right)^2}\\ = \sqrt{0.98^2\left( \sin^2 (t) + \cos^2 (t) \right) + 1 - 0.98^2} = \sqrt{0.98^2 + 1 - 0.98^2} = \sqrt{1} = 1 \end{gather*}
    Hence
    \begin{equation*} L = \int_0^{2\pi} |\vec{r}'(t)|\, dt = \int_0^{2\pi} 1\, dt = \left. t \right|_0^{2\pi} = 2\pi \end{equation*}
    The glider moves with constant speed \(1\text{,}\) so the length of its path equals the elapsed time \(2\pi\text{.}\)
    🔗
    🔗
    🔗

    Remark 4.1.12. Displacement vs Arclength.

    It is important not to confuse displacement with arclength. Here we summarize both:
    🔗
    • \(\left|\int_{a}^{b} \vec{r}^{\prime}(t) d t\right|\) is computing the displacement (straight line distance) from the endpoint of \(\vec{r}(a)\) to the endpoint of \(\vec{r}(b)\text{.}\)
      🔗
      🔗
    • \(\int_{a}^{b}\left|\vec{r}^{\prime}(t)\right| d t\) is computing the arc length (distance travelled along \(\vec{r}(t)\) ) from the endpoint of \(\vec{r}(a)\) to the endpoint of \(\vec{r}(b)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 4.1.13.

    Below is the graph of \(\vec r\left(t\right)=\langle t ,\ln\left(\cos\left(t-\frac{\pi}{2}\right)\right)+1 \rangle, 0 \lt t \lt \pi\text{.}\) Calculate the displacement vector from the endpoint of \(\vec{r}\left(\frac{\pi}{2}\right)\) to the endpoint of \(\vec{r}\left(\frac{\pi}{2}+\arccos (1/e)\right)\text{.}\)
    🔗
    Compare this to the length of the curve from the endpoint \(\vec{r}\left(\frac{\pi}{2}\right)\) to the endpoint of \(\vec{r}\left(\frac{\pi}{2}+\arccos (1/e)\right)\)along \(\vec{r}(t)\) colored in light blue.
    🔗
    Solution 1.
    First we find the two endpoints. At \(t=\frac{\pi}{2}\text{:}\)
    \begin{equation*} \vec{r}\left( \tfrac{\pi}{2} \right) = \left\langle \tfrac{\pi}{2},\ \ln\left( \cos (0) \right) + 1 \right\rangle = \left\langle \tfrac{\pi}{2},\ \ln (1) + 1 \right\rangle = \left\langle \tfrac{\pi}{2},\ 1 \right\rangle \end{equation*}
    At \(t=\frac{\pi}{2}+\arccos (1/e)\text{,}\) using \(\cos\left( \arccos (1/e) \right) = \frac{1}{e}\text{:}\)
    \begin{equation*} \vec{r}\left( \tfrac{\pi}{2}+\arccos (1/e) \right) = \left\langle \tfrac{\pi}{2}+\arccos (1/e),\ \ln\left( \tfrac{1}{e} \right) + 1 \right\rangle = \left\langle \tfrac{\pi}{2}+\arccos (1/e),\ 0 \right\rangle \end{equation*}
    The displacement vector from the first endpoint to the second is their difference:
    \begin{equation*} \left\langle \tfrac{\pi}{2}+\arccos (1/e) - \tfrac{\pi}{2},\ 0 - 1 \right\rangle = \left\langle \arccos (1/e),\ -1 \right\rangle \end{equation*}
    so the displacement (straight line distance) is \(\sqrt{\arccos^2 (1/e) + 1} \approx 1.56\text{.}\)
    🔗
    🔗
    Solution 2.
    For the length of the curve we differentiate, using the chain rule on the second component:
    \begin{gather*} \vec{r}'(t) = \left\langle 1,\ -\tan\left( t - \tfrac{\pi}{2} \right) \right\rangle\\ |\vec{r}'(t)| = \sqrt{1 + \tan^2\left( t - \tfrac{\pi}{2} \right)} = \sqrt{\sec^2\left( t - \tfrac{\pi}{2} \right)} = \sec\left( t - \tfrac{\pi}{2} \right) \end{gather*}
    where we dropped the absolute value since \(t-\frac{\pi}{2}\) lies in \(\left[ 0, \arccos (1/e) \right]\text{,}\) which is inside \(\left[ 0, \frac{\pi}{2} \right)\) where the secant is positive. Hence
    \begin{gather*} L = \int_{\frac{\pi}{2}}^{\frac{\pi}{2}+\arccos (1/e)} \sec\left( t - \tfrac{\pi}{2} \right) dt =\\ u = t - \tfrac{\pi}{2}, \quad du = dt, \quad t = \tfrac{\pi}{2} \Rightarrow u = 0, \quad t = \tfrac{\pi}{2}+\arccos (1/e) \Rightarrow u = \arccos (1/e)\\ \int_0^{\arccos (1/e)} \sec (u)\, du = \left. \ln\left| \sec (u) + \tan (u) \right| \right|_0^{\arccos (1/e)} = \ln\left( e + \sqrt{e^2-1} \right) - \ln (1) =\\ \ln\left( e + \sqrt{e^2-1} \right) \end{gather*}
    using \(\sec\left( \arccos (1/e) \right) = e\) and \(\tan\left( \arccos (1/e) \right) = \sqrt{e^2-1}\text{.}\) Numerically the arc length is \(\ln\left( e + \sqrt{e^2-1} \right) \approx 1.66\text{,}\) which is larger than the displacement \(\approx 1.56\text{,}\) as expected: the straight line is the shortest path between the two endpoints.
